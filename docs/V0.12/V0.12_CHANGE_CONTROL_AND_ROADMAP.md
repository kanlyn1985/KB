## 3. P0/P1/P2 分级

### P0（触发即 STOP）
- analytics 写任何 frozen 面（assertions/kg_*/信号表/hypothesis 状态/task 状态）；
- 报告成为自动 action 触发器（报告→自动 proposal/自动 maintenance——
  Proposal ≠ Decision 破）；
- identity 引入 timestamp/random/uuid4；
- 把 human decisions 用作学习信号（Governance Feedback 永久红线破）。

### P1（实现期必须解决）
- 窗口语义定标（occurred_at 秒级精度同秒 tie——seq 锚模式延续）；
- 浮点聚合确定性（round 策略 + canonical 排序锁定——实现期测试锚定精确相等）；
- payload 尺寸监控（大基数聚合超 metadata 实用上限 → migration 19 触发评估）。

### P2（future optimization）
- cursor 降采样（长窗口趋势）· 报告 diff 视图 · metrics 白名单扩展 ·
  可视化导出 · analytics→proposal 的"建议发起"界面（仍 human-first）。

## 4. Out of Scope（V0.13+ / 永久）

- V0.13+：counterfactual reasoning runtime（机制比对 level-2+ 前置）、
  mechanism understanding layer（ontology 冻结前置）、ontology evolution
  layer（同前置；proposal-only 模式可复用 V0.11 先例）；
- 永久禁止：multi-agent autonomous / learning 自动改规则 / LLM truth source /
  CausalProjection 直写 kg_* / system 自动执行 maintenance / 自动 conflict
  resolution / hypothesis→assertion 直通 / proposal→knowledge mutation /
  **governance feedback learning（human decisions 作为学习信号）** /
  analytics→auto action。
