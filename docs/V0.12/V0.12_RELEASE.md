## Architecture Summary（第八层——观察/理解层）

```text
七层 frozen 产物（全部只读消费）
  ↓ 确定性聚合（纯函数——round(4) + canonical 排序）
KnowledgeAnalyticsRuntime（V0.12）
  ↓ KnowledgeMetricReport（immutable + anr_ fingerprint）
graph:analytics-report-create（唯一新活动——审计）
  ↓
Existing governance flow（human 阅读 report → 自行决定发起 V0.11 proposal）
```

三不变量：Observation ≠ Truth（零 assertion/flag/status 写入实测）·
Proposal ≠ Decision（报告↛proposal/task 零自动桥——010 计数实测）·
Human = Final authority。

## Metric Boundary（五项白名单——禁止扩展）

knowledge_growth（计数，零解释）· knowledge_drift（lifecycle 转移计数，
零 correction 语义）· governance_efficiency（completed/created 比例，零
human decision 正确性评价）· proposal_resolution_rate（lifecycle 分布，
零 accepted=truth 推断）· causal_coverage_trend（边/断言比例，零
more-causal=better 推断）。扩展需新任务书。

## Query Model

AnalyticsQueryRuntime：报告源唯一 = akb_provenance（零新表）；scope/metric
过滤（白名单 fail-close）；keyset cursor（canonical JSON + 指纹校验 +
query binding——V0.10/0.11 模式复用；零 OFFSET）；ordering 固定 report_id
ASC；limit cap 500。

## Determinism Guarantees（FINAL 独立复算）

same input → same report_id / same fingerprint / same metrics ✓ ·
diff input → diff identity ✓ · 五 metrics 白名单唯一性 ✓ ·
零 timestamp/random/runtime ordering ✓。

## Known Limitations（P1）

1. **P1-01** provenance scan scalability——报告查询全表 LIKE 扫描（V0.10 P1

2. **P1-02** cursor payload growth——报告 id 粒度 canonical JSON（当前
   <200B/cursor）；
3. **P1-03** analytics report storage decision——即时聚合可重算 vs 物化
   面的权衡（P2 materialized view 候选关联）。
