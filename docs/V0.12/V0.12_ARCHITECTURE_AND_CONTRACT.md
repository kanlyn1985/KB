## 2. 三不变量（本层宪法）

1. **Observation ≠ Truth**：报告是观察聚合——零 assertion/flag/status 写入；
2. **Proposal ≠ Decision**：报告可提示"某类信号值得 review"，但提案仍必须
   经 V0.11 human-first 通道（报告→proposal 无自动桥）；
3. **Human = Final authority**：报告供 human 阅读；系统零自动行动。

## 3. Contract：KnowledgeAnalyticsRuntime（future——零实现）

```text
create_report(*, scope: str, window: dict | None, actor_id) -> KnowledgeMetricReport
    scope 白名单: "global" | "signal_type:<t>" | "conflict_type:<t>"
                  （未知 scope → E-V12-ANALYTICS-INVALID fail-close）
    identity: report_id = "anr_"+SHA256(canonical_json({scope, window,
              signals_digest, audit_digest}))
      —— signals_digest = akb_health_signals/conflict_records 内容摘要
         （sorted canonical）；audit_digest = 相关 provenance 活动摘要
      —— 同库状态同窗口 → 同 report_id（零 timestamp/random 入 hash）
    deterministic: metrics 计算为纯函数；浮点聚合 round(4) + canonical
                   排序（metric_type, subject ASC）
    failure: E-V12-ANALYTICS-INVALID（scope 非法/window 非法/数据面缺失）
    provenance: graph:analytics-report-create（report_id/scope/digests/
               entry_count）

KnowledgeMetricReport（frozen dataclass）
    report_id / scope / window_ref / metrics(tuple——{metric_type, subject,
    value, trend, detail} canonical 序) / fingerprint / provenance_refs

get_report(report_id) -> report | None（provenance 重放；零 fabricate）
list_reports(*, scope=None, cursor=None, limit=100)
    —— V0.10/0.11 keyset cursor 模式复用（指纹校验 + PAGE-INVALID guard
       limit≤500）
```
