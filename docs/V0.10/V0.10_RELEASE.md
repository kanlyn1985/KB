## Governance Boundary

实测）· Query ↛ Knowledge mutation（只读面全隔离实测）· Registry Snapshot ↛
Runtime behavior mutation（registry 内容零变化实测）· 五条既有直通禁令全延续。

## Limitations（P1，不阻断 freeze——缓解路径已定义）

1. **P1-01** persistence scale——跨进程并发写需应用层显式串行化（SQLite 单写者
   模型；同 connection SAVEPOINT 串行已实测）；
2. **P1-02** cursor scale——keyset 稳定性优于 OFFSET 已验证；深分页 cursor
   降采样属未来项；
3. **P1-03** snapshot payload growth——条目摘要级 <1KB/快照，10^3 条目触及
   metadata 实用上限（migration 18 触发条件监控）；
4. **P1-04** concurrent writer model——单写者约定延续。
