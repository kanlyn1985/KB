## 3. P0/P1/P2 分级

### P0（触发即 STOP）
- 提案自动执行（completed 语义系统触发——governance human-only 破）；
- 提案写 akb_assertions/kg_*/hypothesis 状态（knowledge mutation）；
- V0.8 task 生命周期语义被修改（超出枚举扩展）；
- conflict 裁决性标注被提案自动变更（Conflict ≠ Resolution 破）。

### P1（实现期必须解决）
- signal.target_ref → hypothesis 解析规则（entity 型信号无直接 hypothesis——
  created_from 锚派生，实现期定标并测试锚定）；
- proposal spec 确定性模板（同信号同文本——零自由文本漂移，实现期测试锁定
  文本精确相等）。

### P2（accepted 候选）
- 提案优先级排序视图（severity/score 加权——analytics 前身）；
- 提案-裁决关联分析；
- 批量提案生成（同快照多信号一键提案集——批量幂等语义）。

## 4. Out of Scope（V0.12+ / 永久）

- V0.12+：counterfactual reasoning runtime（边界契约已预埋——需机制比对
  level-2+ 与 ontology 冻结）、Mechanism Understanding Layer（同前置）、
  Semantic Analytics Layer、conflict arbitration workflow（REJECTED——自动
  truth selection 逸出风险）；
- 永久禁止：multi-agent autonomous / learning 自动改规则 / LLM truth source /
  CausalProjection 直写 kg_* / system 自动执行 maintenance / 自动 conflict
  resolution / hypothesis→assertion 直通 / proposal→knowledge mutation。
