## Governance Boundary（六条禁止路径全 fail-close 实测）

Proposal ↛ akb_assertions / ↛ kg_nodes+kg_edges / ↛ hypothesis 状态 /
ProposalRuntime ↛ task 自动迁移（created 后零系统迁移）/
spec ↛ 裁决性结论（固定模板"Please review ..."）/
Conflict proposal ↛ Resolution（status 零变更实测）。

## Determinism（FINAL 独立复算）

同输入（同 health/conflict 快照 + 同规则）→ 同 proposal_id / 同 fingerprint /
同 task_id（V0.8 verification_task_identity 原样复算成立——信号行粒度）；
差异输入 → 差异 identity；零 timestamp/零 random/零 runtime ordering。
