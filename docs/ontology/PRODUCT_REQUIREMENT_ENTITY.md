## 2. 产品需求类实体展开（10 类）

```
产品需求类（展开）
├─ P1 产品实体        OBC / DCDC / CCU(集成) / 低压供电 / 逆变(V2L/V2G)
├─ P2 功能实体        充电功能 / 放电功能 / DCDC转换 / 反供电 / 休眠唤醒 / 反向预充
├─ P3 参数实体        电压 / 电流 / 功率 / 频率 / 效率 / 功率因数 / 纹波 / 精度 / 过冲 / 动态响应
├─ P4 约束实体        范围约束(85~265V) / 精度约束(±1%) / 限值约束(≤5%) / 条件约束(满载时)
├─ P5 保护实体        过压/欠压/过流/短路/过温/绝缘监测/漏电/反接
├─ P6 状态机实体       OBC状态机 / DCDC状态机 / 休眠唤醒状态机 / AC Relay状态机
├─ P7 故障实体        故障ID / 触发条件 / 执行动作 / 恢复条件

├─ P9 标准实体        GB/T 40432 / ISO 16750-2 / IEC 60664-1 / Q/MA 企标
└─ P10 需求条目实体    需求容器（枢纽，见 §3）
```

## 4. 参数节点槽位全集（从曼岛需求归纳）

```
通用槽位模式（所有参数节点共用）：
slot = {范围, 额定值, 控制精度, 检测精度, 上报精度, 过冲, 纹波, 动态响应,
        条件, 异常处理(fault_ref), 验证方法, 验证标准, ASIL}

输出电压实例：  范围 336-750V（满载 550~750V）| 控制精度 ±1% | 上报精度 ±1%
               | 过冲 ≤5% | 抛负载 ≤1000V或电池+50V | 检测精度 ±3V(AC侧)
输出电流实例：  最小 0.5A | 稳流精度 ≤1% | 误差 >10A:±2%/<10A:±0.2A
               | 纹波 峰峰≤10%额定/平均≤5%额定(10Hz~150kHz) | 过冲 ≤5%或≤0.5A | 检测精度 ±0.5A
输入电压实例：  范围 85~265VAC | 电网适应性(暂降动态调节不停机) | 异常→故障引用
功率实例：      额定功率 | 降额曲线(HVDC电压/输入电流/冷却液温度 三张)
```

## 5. 挂载机制（需求文本 → 节点 + 槽位 + 值）

### 5.1 解析成分（6 个可解析部分）

```
"OBC充电——输入电压范围：85V至265V AC（单相）"
  │         │          │      │        │
  ①产品限定词  ②参数名   ③槽位线索  ④值表达式  ⑤条件
  ⑥异常引用："见故障列表 MI-MD-31080/31081"

① 产品限定词：标题前缀（OBC充电/OBC放电/DCDC/低压供电）→ 产品子树
② 参数名：电压/电流/功率/频率/效率/功率因数 + 修饰词（输入/输出/额定/最小）→ 参数节点
③ 槽位线索：范围/精度/纹波/过冲/误差/动态响应/降额 → 槽位
④ 值表达式：见 5.3
⑤ 条件：充电模式/满载/常温/启动时 → condition 槽位
⑥ 异常引用 → fault_ref 边（指向故障实体）
```

### 5.2 挂载决策表

| 需求形态 | 挂载结果 | 例子 |
|---|---|---|
| 单参数单槽位 | 1 个挂载单元 | "输入电压范围 85~265V" |
| 单参数多槽位 | 多个槽位值 | 范围 + 满载范围 |
| 多参数（"…和…"） | 多节点挂载 | "输入电压和输出电压" |
| 条件分段值 | 同槽位多 (条件,值) 对 | 输出电流误差 >10A/<10A 两档 |
| 引用故障 | 额外建立 fault_ref 边 | 范围需求 → 故障实体 |
| 信号级（SWRD） | 挂到信号实体 | SW4-16298 → 绝缘监测 |

### 5.3 值表达式语法（待补全）

```
85V至265V          → range {min:85, max:265, unit:V}
336-750VDC         → range {min:336, max:750, unit:V}
≤±3V               → number {value:3, comparator:≤±, unit:V}
6≤AC≤32A           → range 双侧
>10A: ±2% / <10A: ±0.2A → 条件分段（(condition, value) 对）
```

### 5.4 挂载单元数据结构

```
挂载单元 = {
  node_id: "OBC/性能参数/输入特性/输入电压",
  slot: "range",
  value_type: "range|number|condition",
  value: {min: 85, max: 265, unit: "V", comparator: null},
  condition: "充电模式（单相）",
  asil: "QM",
  source_req: "MI-MD-13065",      ← 需求条目 ID（证据）
  project: "曼岛",
  verification: "电气性能测试",
  standard: "GB/T 40432-2021",
  fault_refs: ["MI-MD-31080", "MI-MD-31081"]
}
```

一条需求 = 1..N 个挂载单元；挂载后**项目实例（曼岛）在节点槽位上获得值**——"本体相同、属性随项目变"的实现：曼岛项目在"输入电压.range"有 {85~265V}，VAVE 项目可有自己的值，通用槽位存标准值。
