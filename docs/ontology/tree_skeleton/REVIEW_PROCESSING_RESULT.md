## 关键发现

1. **75.4% 的复核队列是噪声**——钉钉文档提取时的 HTML 注释、HTTP 错误、
   日期/版本标题等。这些不是"未落位知识"，是**提取层缺陷**（后续可在
   extract_units 阶段直接过滤，从源头减少复核量）。
2. **规则重判仅 0.4% 成功**——印证复核队列的内容确实无法用关键词规则匹配
   （当初进队列的原因），LLM 判断已到规则能力上限。
3. **人工复核 10,774 条工程内容**——主要是孤立表格行、无上下文片段、
   跨域内容（如"损耗分布分析与装配工艺无关"），需要领域专家判断。
4. **非工程内容 3,261 条**——学习方法/心理学/项目管理等，与增枝决策一致
   （暂不算知识库知识），已单独标记，不参与落位。
