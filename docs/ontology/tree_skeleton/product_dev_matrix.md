# OBC/DCDC 产品开发完整矩阵（粗粒度 · v0.5 草稿）

> 来源：`产品开发流程.adoc.md` / `结构开发流程V5.3.adoc.md` / `01_ASPICE开发流程.md` / `项目开发流程＆汽车质量管理体系.adoc.md`（IATF 16949）

## 一、阶段门（时间轴）

| 阶段 | 目标 | 重点控制风险 | 门禁评审 |
|------|------|--------------|----------|
| RFQ | 确定可实现总方案 + 验证计划 | 总方案不可实现 | RFQ 方案评审 |
| EVT1 | 方案设计实现 + 样机验证需求满足度 | 振动 + 热 | EVT1 设计评审 |
| EVT2 | 设计优化 + 开模，需求满足度 90% / 关键 100% | 可制造性 | EVT2 设计评审 + 开模评审 |
| ET | 解决 DV 暴露的设计问题，全面整改 | 量产遗留问题 | 变更评审 |
| DV | 设计验证 | 设计缺陷 | DV 评审 |
| PV | 生产验证 | 工艺/一致性 | PV 评审 |
| SOP | 量产 | 批量质量 | SOP 评审 |

## 二、专业域 × 阶段 交付物矩阵

### 需求（REQ）—— 全阶段贯穿
| 要素 | 说明 |
|------|------|
| 产品需求分析 | 按 DFMEA 七大功能组展开：General / Process-Production / Mechanical / Climatic / Electrical / Thermal / EMC |
| 功能安全需求 | ISO 26262 / GB/T 34590（安全目标、ASIL 等级） |
| 接口需求 | 整车匹配、CAN 矩阵、连接器定义 |
| 客户标准解读 | TS / SOR / SOW + 偏差矩阵 |
| 需求追溯矩阵 | 需求 → 设计 → 代码 → 测试 双向追溯 |

### 电子 EE
| 阶段 | 要素 |
|------|------|
| RFQ/EVT1 | 电子布局图、热损耗图、安规设计表 |
| 全阶段 | 主功率拓扑设计（OBC 电路拓扑）、原理图设计、PCBA Layout |
| 全阶段 | PCB 流程管理、硬件版本管理、安规设计流程 |
| 全阶段 | 热测试流程、内特性测试流程、功能安全管理流程、8D 报告流程 |

### 软件 SW（ASPICE）
| 过程域 | 要素 |
|--------|------|
| SYS.1–SYS.5 | 需求获取 → 系统需求分析 → 系统架构设计 → 系统集成测试 → 系统合格性测试 |

| SWE.2 | 软件架构设计（SWAD） |

### 结构 ME
| 阶段 | 要素 |

| EVT1 | 结构限制图、结构设计细化、热仿真报告、力学仿真报告、公差分析、安规检查表、结构设计评审、打样、POP、样机验证、DFMEA 第一次、磁件检核表、装配说明书、结构拆机报告 |
| EVT2 | 结构设计更新、凝露分析、气密测试、DFMEA 第二次、开模评审、2D 图纸发布、PBOM 发布、特殊特性清单、PCBA 组装工艺、产品组装工艺、包装方案 |
| ET | DV 试生产问题解决、拆机检查、变更整改、安规检查 |
