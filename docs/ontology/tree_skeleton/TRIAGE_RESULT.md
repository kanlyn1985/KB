# 工程复核内容二次筛选结果（2026-08-18）

> 目的：10,774 条工程复核内容中，筛出**真正值得人工审核**的，减少无效人工工作
> 方法：LLM（EVT/deepseek-v4-flash）逐条判定 worth_review
> 脚本：`llm_landing/triage_review.py`
> 输入：`review_processing/manual_review_engineering.jsonl`
> 输出：`review_processing/triage/`

## 筛选结果

| 分类 | 条数 | 占比 |
|---|---|---|
| **值得人工审核** | 5,109 | 47.4% |
| **不值得（归档）** | 5,665 | 52.6% |

LLM 错误：2 条（<0.1%，默认保留审核）

## 判定标准

**值得（worth_review=true）**：
- 含实质工程信息（参数/方法/步骤/问题/结论/经验）
- 操作说明（如 ipconfig 查看 IP、共享设置）
- 工程注意事项、经验条目
- 可能含结论的引导句（"判定如下："等，需结合上下文）

**不值得（worth_review=false）**：
- 纯文件名/标题（"LC数字控制交流.pptx"、"附表"、"评估材料"）
- 无信息量碎片（"分支路径："等）
- 重复性空泛建议

## 关键数据

**值得审核 5,109 条构成**：
- para 4,267（83.5%）——操作步骤、注意事项、方法描述
- heading 350（6.9%）——含具体信息量的标题（如"3.1、查看本机IP方法"）
- experience 269（5.3%）——经验条目
- table_row 220（4.3%）——含数值的表格行

**不值得 5,665 条构成**：
- 绝大多数是纯文件名/章节标题（heading 3,538 条中的大部分 + 文件名类 para）

## 意义

人工审核量从 **10,774 → 5,109 条（减少 52.6%）**，且保留的都是含实质信息的
内容。5,109 条中 para 占 83.5%，多数是"有信息但骨架无对应节点/上下文不足"，
适合人工确认归属或作为增枝依据。
