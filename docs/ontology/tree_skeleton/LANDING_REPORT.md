## 三、归属率分析

**100% 分类**（产品平台/芯片参考）：文档类型集中，规则覆盖完整。

**62-76% 分类**（规范标准/可复用资产/经验成长/开发方法）：
- 规范标准 64%：AUTOSAR 原始 ARXML 规范件（英文 XML）无归属（129 份 0%）——这些是机器可读规范，非知识文档，建议标记为"规范源文件"不入树
- 可复用资产 62%：代码资产/文档模板/工具配置（12 份 0%）——属过程维度的工具资产
- 经验成长 76%：分享/培训材料（无规则）——属 Q 域知识
- 开发方法 76%：部分英文教程/配置无规则

**共性结论**：0% 文档多为"工具资产/英文规范源文件/元数据"三类，不是知识内容，建议归入"工具资产"节点或标记不入树。
