# 查询处理流程设计（讨论稿）

> 状态：讨论稿 v0.1（2026-08-04）
> ✅ 已确认：查询理解采用"LLM + 规则"混合架构（LLM 出候选、代码白名单裁决、确定性兜底）
> ✅ 颗粒度已认可：下述 6 步拆解（可映射到代码函数）
> ❓ 细节待定：8 类实体如何展开定义（下一轮讨论）

---

## 0. 总览

```
问题 → ①实体识别 → ②验证消歧 → ③意图拆分 → ④取值 → ⑤合并组装 → ⑥输出
       文本→候选     候选→实例     实例→子查询   子查询→值   值→ContextPack   回答
```

## 1. 实体识别（文本 → 候选）

```
输入：问题文本
1a 预处理：NFKC 归一化、全角→半角、去标点噪声
1b 术语表匹配（确定性主路径）：
    扫 8 类白名单词表（术语/别名/项目名/物料/标准号…）
    最长匹配优先，记录 span；命中项直接入候选池
1c 线索词匹配（非实体，槽位线索）：
    属性线索表：限值/范围/精度/条件/带宽/响应时间…
    关系线索表：依据/由谁/哪个阶段/验证方法…
    意图词表：是多少/谁负责/对比/历史/依据…
1d LLM 候选（可选层，出宽候选）：
    输出 [{实体文本, 类型, 候选ID, 置信度}]——只提名人，不裁决
1e 合并：规则命中项（高优先）∪ LLM 独有项（需过白名单）
决策：同一 span 规则与 LLM 指向不同 → 以规则为准

输出：实体候选 [{span, 类型, 候选节点IDs, 置信度, 来源(规则/LLM)}]
     线索 {属性线索[], 关系线索[], 意图线索[]}
```

## 2. 实体验证与消歧（候选 → 实例）

```
2a 白名单验证（代码强制）：候选查树——存在→node_id；不存在→unknown（进待增枝队列，禁止外推）
2b 消歧决策表（顺序执行，命中即止）：
    D1 上下文限定词：问题中产品/项目名（OBC/DCDC/CCU…）过滤候选
    D2 术语表精确匹配：别名完全一致 > 部分包含
    D3 意图偏好：意图对应节点类型优先（查限值 → 约束类优先）
    D4 仍多候选 → 不猜：标记 multi_hit，输出提示"命中多个节点，请指定"
2c 去重：多 span 同 node_id → 合并

输出：实体实例 [{node_id|unknown, 类型, 角色待定, 来源}] + 待增枝队列
```

## 3. 意图判定与子查询拆分（实例 → 子查询队列）

```
3a 意图判定（决策表，主实体类型决定主意图）：
    产品需求实例+属性线索 → 值查询
    工程实体实例+角色词   → 过程查询
    两项目实例+值线索     → 对比查询
    失效/问题词           → 经验查询
    标准号/依据词         → 追溯查询
    纯文档词              → 文档查询
3b 子查询拆分规则：
    R1 每个主目标实体 → 一个子查询（多参数 → 多子查询）
    R2 单项目过滤器 → 附加到每个子查询
    R3 对比意图（双项目）→ 同节点 × 2 项目并行取值
    R4 追溯线索 → 追加证据子查询（目标=标准/条款节点）
    R5 经验线索 → 追加经验子查询（目标=经验库）
    R6 版本线索 → 子查询附加版本裁决开关

输出：子查询队列 [{目标节点, 属性线索, 关系线索, 项目过滤器, 版本开关, 意图}]
```

## 4. 取值链（子查询 → 值 + 证据）

```
三级取值链（逐级下探，记录来源标记）：
  L1 项目挂载值：过滤器有项目 → project_instance(node_id, project_id)
     → 值 + 来源="project:XXX" + 证据(该项目文档)
  L2 通用值：node.attributes[属性线索]（标准限值/典型值）
     → 值 + 来源="generic" + 证据(标准条款/行业值)
  L3 缺省：无值 → missing，输出"该节点无此属性值"
证据子查询独立取：节点 → evidence 边 → 标准条款/文档章节 → 原文摘录
版本裁决：开 → 查变更记录取最新生效值（旧值标 deprecated）

输出：每子查询 {值, 来源级别(L1/L2/L3), 证据链[], 条件}
```

## 5. 结果合并与组装（子查询结果 → ContextPack）

```
合并规则：
  M1 多值子查询 → 列表 [{参数, 值, 来源, 条件}]
  M2 对比查询 → 并排 {参数: {项目A: 值A, 项目B: 值B, 差异标注}}
  M3 证据子查询 → 挂接对应值的 evidence
  M4 经验子查询 → 独立区块（历史记录/无记录）
组装：ContextPack = {targets[], attributes[], evidence[], project_context,
                     knowledge_gaps[], recommended_answer_strategy}
判定（evidence_judge）：
  sufficient：主值有证据且完整（L1 或 L2+证据）
  partial：主值无证据 / 经验子查询无记录
  insufficient：全部 missing 或主目标 unknown
```

## 6. 输出模板（ContextPack → 回答）

```
值查询    → "{参数} 限值 = {值}（{来源级别}）；条件：{条件}；依据：{条款}"
过程查询  → "{活动}：负责={角色}；交付={交付物}；阶段={阶段}"
对比查询  → "{参数}：{项目A}={值A} vs {项目B}={值B}"
经验查询  → "历史记录：{记录摘要 | 无}"
追溯查询  → "{参数} {值} 依据 {标准号} §{条款}：{原文摘录}"
文档查询  → "相关内容见 {文档名} §{章节}"
未覆盖    → "「{词}」不在知识树中，已记录待增枝"
```

## 7. 8 类实体处理管线（角色与取值一览）

| 实体类 | 识别特征 | 白名单验证 | 检索角色 | 取值方式 | 缺失行为 |
|---|---|---|---|---|---|
| 产品需求 | 术语表/别名命中 | 参数/功能/约束节点存在 | 主目标 | 属性槽位值（项目实例优先） | not found + 待增枝 |
| 工程实体 | 阶段/活动/角色名 | 活动/阶段节点存在 | 主目标（过程类） | 角色/交付物/阶段属性 | 同上 |
| 项目实例 | 项目名 | 项目实例表存在 | 过滤器/对比对象 | 过滤 + 挂载值 | 返回通用值+提示指定项目 |
| 物料 | 物料名 | 物料节点存在 | 主目标（物料类） | 规格属性 | 提示 |
| 质量/失效 | 失效模式/问题词 | 经验库节点 | 主目标（经验类） | 历史记录/规避措施 | 提示无记录 |
| 供应商/组织 | 供应商名 | 供应商节点 | 归属补充 | 信息属性 | 跳过不阻塞 |
| 证据/标准 | 标准号 | 标准/条款节点 | 追溯目标/可信锚 | 条款内容 | 提示标准未入库 |
| 变更/治理 | 版本词 | 版本节点 | 版本裁决 | 最新有效值 | 取当前值 |

## 8. 关键规则

1. **意图决定主目标**：同一批实体，意图不同角色不同（"纹波限值"→产品需求主；"哪个条款"→证据主；"谁负责"→工程实体主）
2. **实体与线索分离**：限值/条件/依据等是槽位线索，不是实体；实体识别只认 8 类白名单
3. **同类多实体 = 主目标集合**：各自取值、列表输出
4. **消歧顺序**：限定词 > 精确匹配 > 意图偏好 > 不猜（提示用户）
5. **项目实例两用法**：单项目=过滤器；对比问题=对比对象（主目标集合）
