## 3. Test Strategy

- 行为级优先（延续项目原则——非源码检查测试）：
  - Schema：投影幂等（同状态双跑同 Graph）/ 确定性 id / 失效标记级联；
  - Identity：L1/L2/L4 正例合并 + **相似度负例（禁止自动 merge——任务书红线）** +
    merge/split 回滚 + alias 冲突拒绝；
  - Persistence：migration 幂等 / 失效传播 / graph:* 审计落库；
  - Query：五级链回溯 exact（禁 subset/superset）/ k-hop 边界 / 状态过滤 / 确定性排序；
  - 回归：V0.1/V0.2/V0.3/V0.4 全量 + Golden 30/40/55/23 零下降。
- Golden Dataset（IMPL-004 期）：P/N/D 分层（投影正例/拒绝与隔离/矛盾与治理投影）。

## 4. Risks

| 风险 | 缓解 |
|---|---|
| 误合并实体污染查询 | 红线 M-01..04（相似度仅建议）+ 治理队列 + merge/split 回滚 |
| 投影与源漂移 | 投影幂等 + fingerprint 锚 + 失效级联（审计事件） |
| 图遍历失控 | MAX_HOPS 上限 + 查询确定性排序 |
| 规模膨胀（全量投影） | 投影按 validated 优先 + namespace 分域（DomainPack） |
| frozen 边界破坏 | 每 IMPL 轮 frozen diff 审计（V0.4 先例） |
| 治理负担 | merge/split 仅建议制；治理队列聚合视图 |

## 5. Out of Scope（V0.5 明确不做）

graph-aware reasoning（V0.6 候选）/ 跨节点自动聚类 / 分布式图存储 / 物化视图缓存 /
外部图数据库依赖（单节点 SQLite 优先——AGENTS 约定）。
