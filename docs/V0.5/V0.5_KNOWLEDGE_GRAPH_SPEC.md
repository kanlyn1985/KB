# V0.5 Knowledge Graph Spec — Knowledge Graph Layer

- Document ID: AKB-DD-V05-001 · Version: V1.0 · Status: Design Baseline（DESIGN READY 待评审）
- 上游基线：V0.4 ACCEPTED / RELEASE BASELINE（37ec6ea）
- 约束：本文档为设计——不修改 V0.4 frozen code；不改 Assertion 生命周期；不改
  inferred→validated governance；不改数据库；不执行 migration。

## 1. Knowledge Graph Layer 定位

V0.5 在既有事实栈上引入**投影层**（projection layer）——Knowledge Graph 是
Validated Knowledge 的**派生视图**，不是事实来源：

```text
【V0.4 现状】                    【V0.5 投影】
Evidence（唯一可信来源）    →    Graph Node: Evidence
  ↓ SemanticUnit                  ↕ Node: SemanticUnit
  ↓ Assertion                     ↕ Node: Assertion
  ↓ Inference                     ↕ Node: Inference
Validated Knowledge              Graph Query / Traversal / Audit
```

定位三原则：
KG-01 **Graph 不成为事实来源**——Evidence 仍是唯一可信来源（设计原则 5）；
      Graph 任一元素必须可回溯到 Assertion/Evidence，无法回溯的 Graph 元素非法；
KG-02 **投影非拷贝**——Graph 是 Assertion 层的语义索引（entity/relation 视图），
      重建必须幂等（同输入 → 同 Graph，继承 V0.3/V0.4 fingerprint 锚语义）；
KG-03 **治理边界不变**——Graph 元素的生命周期完全跟随其源 Assertion
      （Assertion deprecated/rejected → 投影元素失效标记，不物理删除——INV-005 历史完整）。

## 2. Graph Node 类型设计

| Node 类型 | 源对象 | node_id 规则 | 说明 |
|---|---|---|---|
| EntityNode | Entity Identity Resolution 产物（ENTITY_IDENTITY_SPEC） | `ent_{canonical_id}` | 实体节点；canonical id 全局稳定 |
| SemanticUnitNode | akb_semantic_units | `su_{unit_id}` | 语义单元投影 |
| AssertionNode | akb_assertions | `as_{assertion_id}` | 断言节点（含 assertion_type 元数据） |
| EvidenceNode | akb_evidence | `ev_{evidence_id}` | 证据节点（引用不复制内容） |
| DocumentNode | akb_documents | `doc_{document_id}` | 文档节点 |
| InferenceNode | akb_reasoning_runs + inferred 断言 | `inf_{run_id}` / `as_{assertion_id}` | 推理节点（run 级 + 断言级双粒度） |

节点属性（全部只读投影 + provenance_ref）：
- EntityNode：canonical_form、entity_type（DomainPack 扩展）、alias 列表、confidence；
- AssertionNode：subject_ref/predicate_ref/object、assertion_type、status、confidence、
  temporal_scope（V0.3 temporal semantics 原样引用，不重算）；
- InferenceNode：rule_ref、reasoner_id、depth、rule_input_snapshot 摘要。

## 3. Edge 类型设计

| Edge | 方向 | 语义 | 源 |
|---|---|---|---|
| extracted_from | SemanticUnitNode → EvidenceNode | 单元抽取自证据 | V0.1 既有关系投影 |
| supports | AssertionNode → EvidenceNode | 断言由证据支撑（正向） | evidence_refs |
| contradicts | AssertionNode → AssertionNode | 断言矛盾（V0.3 ConflictRecord 投影：VALUE/STATE/TEMPORAL 等冲突对的双方） | ConflictRecord.sides |
| derived_from | AssertionNode(inferred) → AssertionNode(parent) | 推理派生 | derivation_json.parent_assertions（V0.4） |
| validates | AssertionNode(validated) ← 治理动作 | 人工/validator 校验（govern:validate 审计投影） | akb_provenance + akb_assertion_transitions |
| relates_to | EntityNode ↔ EntityNode | 实体间关系（由 Assertion 的 (subject,predicate,object) 投影；谓词经 DomainPack 映射） | AssertionNode 投影 |

Edge 约束：
- 全部 Edge 携带 provenance_ref（akb_provenance 或源对象 id）；
- contradicts 边不得裁决（指向 ConflictRecord——治理裁决不属于 Graph 职责）；
- relates_to 仅由 validated/candidate 断言投影（hypothesized 不投影——避免未证实结构污染查询）。

## 4. Entity / Assertion 映射关系

```text
Assertion(subject_ref=A, predicate=P, object=B)
    → EntityNode(A) -[relates_to: P]-> EntityNode(B)（object 为 entity_ref 时）
    → EntityNode(A) -[has_attribute: P]-> literal（object 为 literal 时——属性边）
AssertionNode(as_id) -[extracted_from 投影链]-> SemanticUnitNode -> EvidenceNode
```

- 映射纯函数：assertion → graph 元素（确定性；同断言重投影幂等）；
- 断言删除/失效不产生 Graph 孤儿（级联失效标记）；
- 一断言多实体（subject/object 同簇多别名）由 canonical id 收敛——见 ENTITY_IDENTITY_SPEC。

## 5. Graph 与 Evidence 的关系

- Evidence 是唯一可信来源：Graph 的 supports/extracted_from 边保证任何
  EntityNode/relates_to 边可回溯至 ≥1 EvidenceNode（零孤儿实体——孤儿 = 违规）；
- Evidence 内容不复制进 Graph（节点只持 id + 摘要元数据）；
- Evidence content_hash 变更（理论不可能——immutable）→ 投影告警机制。

## 6. Graph 与 Reasoner 的关系

- V0.4 Reasoner 是 Graph 的**生产者之一**：inferred 断言投影为 InferenceNode +
  derived_from 边链（V0.4 derivation chain 原样投影）；
- V0.5 Graph **不是** Reasoner 的输入新通道（避免图驱动推理的自举膨胀）——
  V0.5 范围内 reasoner 输入仍是 akb_assertions；图结构供查询/审计，
  "graph-aware reasoning" 列为 V0.6 候选；
- inferred→asserted 永久禁止在 Graph 层原样继承（治理边界）。

## 7. 查询模型设计

Q-01 **Provenance Query**：任一 Graph 元素 → 五级链回溯
      Node/Edge → Assertion → SemanticUnit → Evidence → Document（GRAPH_PROVENANCE_SPEC）；
Q-02 **Entity Neighborhood**：EntityNode k-hop 邻域（relates_to/supports 过滤）；
Q-03 **Assertion Trace**：AssertionNode → contradiction 邻居（contradicts 边）→
      conflict record 引用；
Q-04 **Inference Chain**：InferenceNode → derived_from 链展开（V0.4 trace_inference_chain
      图投影）；
Q-05 **Status-aware**：全部查询默认过滤失效元素（deprecated/rejected 投影标灰），
      audit 模式可显式包含；
Q-06 **确定性**：查询结果排序确定性（canonical 排序——延续项目约定）。

查询 API 走 V0.4 既有 service 模式（只读连接 + 参数化 SQL + 显式排序）；
图遍历深度上限 MAX_HOPS（默认 4，防失控遍历）。

## 8. 与既有 INV / 边界的一致性

- INV-001/004（evidence 可溯/无孤儿）→ KG-01 强制；
- INV-002（derivation 完整）→ derived_from 边直接投影；
- INV-005（历史完整）→ 失效标记而非物理删除；
- INV-009/010（治理/无动作）→ Graph 层零治理动作、零外部触发；
- V0.3 temporal semantics → temporal_scope 只读引用。
