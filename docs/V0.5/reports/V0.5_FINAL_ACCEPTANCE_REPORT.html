4-6. Architecture / Graph Model / Entity Identity

架构闭环实测：Source facts → GraphProjectionService → GraphProjection → GraphPersistenceService → kg_* → GraphQueryService → Node/EdgeView + ProvenanceTrace。 Identity 单一算法（models.node_id/edge_id SHA256 canonical）——query.py/persistence.py 零重算（grep 实测 False）；persistence 中 uuid 仅用于运行期记录 id（projection_id/ invalidation_id），不参与 graph identity。

Entity identity：L1 exact 为自动边界；相似度仅产 MergeCandidate（ER-CMP-003 重执行 PASS）；type 分歧 fail-closed（ER-CMP-002 重执行 PASS）；merge/split/alias 治理未被 Query/Persistence 绕过（Query 零写、governance 走 akb_provenance）。
