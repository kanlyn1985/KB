## 2. 模块所有权边界

| Owner | 拥有 | 禁止 |
|---|---|---|
| DomainPackRuntime | pack 词汇/约束/规则绑定的**声明与加载**；namespace 分配 | 定义推理执行语义；直接写图 |
| RulePackage | 规则集合的**版本化分发**；每包一个 deterministic provider 实例 | 绕过 orchestrator 直接产候选 |
| ReasoningPolicy | 启用/禁用/预算/加载顺序的**版本化决策数据** | 运行时隐式变更 |
| V0.6 frozen 三件（context/orchestrator/provenance） | 编排/闭环机制 | 被修改（扩展只经 JSON 字段与 provider 注入） |
| V0.5 frozen graph | 结构事实 | 被修改 |
| Governance | 状态裁决 + policy/pack 变更批准（human） | 自动化 |

职责单一性检查：推理语义 = Reasoner（provider）；领域词汇/约束 = DomainPack；
分发与启停 = RulePackage/Policy；裁决 = Governance——四权分立，零交叉。

## 3. Contract：DomainPackRuntime

```text
load(pack_dir) -> LoadedPack
    input: 声明目录（JSON/YAML；frozen DomainPack 字段全兼容）
    output: LoadedPack{pack_id, version, namespace, object_types, relation_types,
            terminology, validation_constraints, rule_bindings}
    identity: pack_ref = SHA256(canonical_json({pack_id, version, 内容摘要}))[:16]
    failure: E-V07-PACK-INVALID / E-V07-PACK-NAMESPACE-CONFLICT（fail-closed）
```

## 4. Contract：RulePackage

```text
register(package: RulePackage) -> provider 实例（deterministic ReasonerProvider）
    —— rule_id/rule_version 全部显式；input_pattern 与 V0.4 provider 协议兼容
    identity: package_ref = SHA256(canonical_json(rules + domain_bindings))[:16]
    failure: E-V07-RULE-INVALID / E-V07-RULE-VERSION-CONFLICT
```

## 5. Contract：ReasoningPolicy

```text
activate(policy) -> policy_ref（审计快照落 graph:reason-policy）
    约束: enabled_rules ⊆ 已注册规则；per_domain_budgets 键 ⊆ 已加载 namespace；
    load_order 决定 provider 注入顺序（确定性）
    failure: E-V07-POLICY-INVALID（引用未注册规则/未知域——fail-closed）
```

## 6. Contract：CrossDomainGuard

```text
check(candidate, context) -> pass | E-V07-CROSS-DOMAIN-BLOCKED
    —— 候选的谓词/实体 namespace 必须 ∈ context 允许域；跨域需治理显式放行
       （human 审计事件 graph:cross-domain-allow）
```

## 7. 各 contract 的 input/output/identity/provenance/determinism/failure/status/version

| Contract | input | output | identity | provenance | determinism | failure | version |
|---|---|---|---|---|---|---|---|
| DomainPackRuntime | 声明目录 | LoadedPack | pack_ref | graph:pack-load | 声明式确定性 | PACK-INVALID/NS-CONFLICT | pack_version |
| RulePackage | rules+bindings | provider 实例 | package_ref | 随 graph:reason | 规则语义冻结于版本 | RULE-INVALID/CONFLICT | rule_version |
| ReasoningPolicy | 启停/预算/顺序 | policy_ref | policy_ref | graph:reason-policy | policy 即数据 | POLICY-INVALID | policy_version |
| CrossDomainGuard | candidate+context | pass/blocked | — | 拦截事件审计 | 确定性 | BLOCKED（fail-closed） | 随 policy |
