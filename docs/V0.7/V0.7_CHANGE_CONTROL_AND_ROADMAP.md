## 3. Risks

| 风险 | 缓解 |
|---|---|
| 多域谓词冲突污染图 | namespace 前缀强制 + CrossDomainGuard fail-closed |
| policy 误启用导致候选爆炸 | per-domain budget + 上限继承 V0.6（1024/4） |

| frozen DomainPack schema 误改 | loader 扩展走新文件；schema.py 零触碰（diff 审计） |

## 4. P0 / P1 / P2 风险分级

### P0（触发即 STOP）
- V0.5/V0.6 frozen 语义需要修改才能实现（含 DomainPack frozen schema 类改动）；
- 跨域隔离无法 fail-closed（污染不可避免）；
- provenance 无法携带 policy/pack 维度（七问不可答）。

### P1（设计必须解决后才能进 FINAL）
- namespace 前缀与既有断言（无前缀谓词）的兼容策略未定义——实现期必须先出
  兼容规则（默认：无前缀 = legacy 域，policy 可显式声明其可用性）；
- 多 pack 同 namespace 冲突的治理流未实装——实现期 IMPL-001 必须含治理入口。

### P2（accepted 候选）
- per-domain budget 初值需实测调参（记录于 rule/policy version）；
- load_order 与 provider 注入顺序的交互性能；
- terminology alias 与 V0.3 L4 通道的重复消费（只读无害）。

## 5. Out of Scope（V0.8+）

hypothesis lifecycle / LLM interpretation / 向量检索 / 分布式 / planning-execution。
