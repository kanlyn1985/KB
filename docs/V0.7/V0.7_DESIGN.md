# V0.7 Design — DomainPack Runtime & Multi-domain Reasoning Governance

- Document ID: AKB-DD-V07-001 · Version: V1.0 · Status: DESIGN BASELINE（待评审）
- 基线：V0.6 FROZEN（b317c6e）· V0.6 design 3610c99（frozen，零修改）·
  V0.5 FROZEN（e7a286e）· 性质：DESIGN ONLY——零代码/零 migration/零 frozen 触碰

## 1. 能力边界分析（V0.6 已具备 → V0.7 缺口）

V0.6 frozen 实测能力（kgraph 八模块）：
- GraphReasoningContext 确定性构建（context.py——root 邻域/状态过滤/时态引用）；
- 单一 V0.4 ReasoningEngine 编排（orchestrator.py——BuiltinRuleReasoner 默认 provider）；
- 五级 provenance 闭环（provenance.py——candidate→run→context→assertions→evidence
  →documents，verify_closure）；
- deterministic contract（VC/OC/PC 30 + CONTRACT 20 = 50 项测试锚定）。

**V0.7 缺口（能力边界）**：
1. provider/规则集硬编码为单一 builtin（BuiltinRuleReasoner + v04-rules-v1）——
   无多规则集/多领域并行推理通道；
2. DomainPack 只有 frozen 词汇面（agent_kb/domains/schema.py DomainPack.terminology）
   ——V0.5 DOMAINPACK_ARCHITECTURE 设计的 ontology/predicates/validation_constraints
   无 runtime；
3. 推理无 policy 层——规则启用/禁用、领域白名单、展开预算全部是硬编码常量
   （MAX_DERIVATION_DEPTH=4/MAX_CANDIDATES_PER_RUN=1024）；
4. 多领域隔离缺失——同一图中跨域词汇无 namespace 隔离，DomainPack 间语义冲突
   （同谓词不同域语义）无防护。

## 2. Capability Decision Matrix（§2 候选评估）

**V0.7 PRIMARY CAPABILITY = DomainPack Runtime + Rule/Knowledge Package 管理 +
Multi-domain reasoning isolation（三合一：领域化推理运行时），
配套 Reasoning policy evolution（policy 即版本化数据）。**

## 3. 核心模型

### 3.1 DomainPackRuntime（V0.5 设计 §2 的 runtime 实例化）

```text
pack_id / pack_version          ——版本化；参与全部确定性派生
namespace                       ——谓词/实体类型前缀（"industrial:"/"finance:"）
ontology                        ——entity_types 树 + predicates（domain/range 类型约束）
validation_constraints          ——cardinality/type_compatibility/temporal（只收紧不放宽）
terminology                     ——继承 frozen 词汇面（alias 通道，V0.3 L4 消费不变）
object_types/relation_types     ——**实际 frozen schema 已有**（agent_kb/domains/
                                  schema.py DomainPack dataclass 实测：
                                  object_types/relation_types/answer_contracts/
                                  hidden_context_rules）——V0.7 runtime 直接复用
                                  这些 frozen 类型面，不重新定义 ontology 模型
answer_contracts/hidden_context_rules ——frozen 既有；V0.7 只读消费
rule_bindings                   ——该包实例化的规则参数（rule_id → 参数集，非新语义）
加载契约                         = 现有 loader.py 扩展（JSON/YAML 声明式，frozen 字段
                                  全兼容）；加载失败 → E-V07-PACK-INVALID fail-closed
```

### 3.2 RulePackage / ReasoningPolicy

```text
RulePackage = {package_id, version, rules[](rule_id/rule_version/input_pattern/
               output_pattern/constraints), domain_bindings[](pack_id@version)}
ReasoningPolicy = {policy_id, version, enabled_rules[], per_domain_budgets{},
                   max_derivation_depth, max_candidates, status_filter,
                   load_order[](RulePackage 序——确定性)}
```

- Policy 即版本化数据：变更 = 新 version（禁止隐式改）；
- ReasoningContext 扩展字段：`policy_id/policy_version`（进入 context_id 派生——
  V0.6 contract 的 configuration 集合扩展，向后兼容：缺省 = legacy policy）。

### 3.3 Multi-domain Isolation

- namespace 规则：DomainPack 谓词/实体类型必须带 `ns:` 前缀进入断言/图；
- 跨域推理边界：规则只能消费其 domain_bindings 声明的域；跨域候选 →
  E-V07-CROSS-DOMAIN-BLOCKED fail-closed（治理显式放行除外——human 审计事件）；
- identity 兼容：canonical_id 派生已含 domain_pack_version（V0.6 IMPL-002 实测）——
  V0.7 复用该语义，不重新定义。

## 4. V0.4/V0.5/V0.6/V0.7 四层关系

```text
V0.4 ReasoningEngine + provider 通道（candidate 生命周期——frozen）
V0.5 Graph（kg_* 只读投影/查询——frozen）
V0.6 Context Builder + Orchestrator + Provenance（编排/闭环——frozen）
        ↑ 消费
V0.7 DomainPackRuntime + RulePackage + ReasoningPolicy（领域化推理运行时）
        —— 提供物：多 provider 实例（每 RulePackage 一个 deterministic provider）、
           policy 驱动的 context 约束、跨域隔离守卫
        —— 不变物：单一 ReasoningEngine 原则延续（provider 多实例 ≠ 多引擎）；
           candidate/governance/provenance 语义零修改
```

## 5. Provenance Impact

- 新增 activity 命名空间：`graph:reason-policy`（policy 快照入审计——before/after
  CanonicalJSON）、`graph:pack-load`（DomainPack 加载/版本切换审计）；
- CandidateProvenance 扩展：`policy_id/policy_version/pack_versions`（JSON 字段，
  零表结构变更——延续 V0.6 NO-MIGRATION 路径）；
- 五问扩展为七问：What/Why/From/Context/Version/**Policy/Pack**。

## 6. Determinism / Governance / Migration

- Determinism：同（graph state + rule_version + policy_version + pack_versions +
  context 定义）→ 同候选集；policy/pack 全部版本化 + canonical JSON；
- Governance：policy/pack 变更 = 治理动作（human；graph:reason-policy 审计）；
  候选晋升边界零变化；
- Migration：**NO MIGRATION**——pack/policy 为声明式文件 + provenance 审计事实；
  ReasoningContext JSON 扩展字段（延续 V0.6 路径）。若实现期证明需要 policy 索引表，
  属实现期任务书决策点。
