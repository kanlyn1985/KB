## 3. P0 / P1 / P2 风险分级

### P0（触发即 STOP）
- CausalProjection 直写 kg_* 或修改 frozen 状态机；
- maintenance 自动执行（system cannot modify knowledge 红线破）；
- conflict v2 自动裁决（flag→verdict 自动化）；
- migration 16 修改既有表（非 append-only）。

### P1（实现期必须解决）
- 因果谓词白名单的 DomainPack 实例化跨域一致性（两域同谓词不同语义——
  走 V0.7 namespace 约定）；
- health 信号阈值定标（密度/decayed/orphan 的阈值需实测校准——初值记
  policy/rule version）；
- 机制等价性判定（mechanism_desc 自由文本的互斥判定算法——设计默认
  条件集合互斥（condition_refs 不相交判定），文本语义比对 DEFERRED）。

### P2（accepted 候选）
- causal edge 分页/索引优化；
- health 信号历史趋势视图；
- counterfactual hypothesis 的专用模板。

## 4. Out of Scope（V0.10+ / 永久）

- V0.10+：runtime optimization（registry 持久化/batch view/分页——Candidate D）；
  ReasoningEpisode 聚合视图（若展示需求成立）；
- 永久禁止：multi-agent autonomous（Candidate E——Agent/Planner/Executor 不得
  进入裁决链）/ learning 自动改规则 / LLM truth source / hypothesis→assertion
  直通 / causal→kg_* 直写 / system 自动执行 maintenance。
