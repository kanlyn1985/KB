## 3. Contract：CausalProjectionRuntime

```text
project(*, actor_id) -> CausalProjectionResult
    input: 全库因果谓词断言（causes/caused_by/enables/prevents——谓词白名单
           属 DomainPack 实例化参数，V0.7 frozen 通道）
    output: {projection_id, fingerprint, causal_edge_count, provenance_ref}
    identity: projection fingerprint = SHA256(canonical_json(sorted edges))
    存储: akb_causal_edges（migration 16；全量重投影幂等——同 fingerprint
          零重复写入）
    failure: E-V09-CAUSAL-INVALID（源断言缺 provenance/端点实体缺失——
             fail-closed 不 fabricate）
    provenance: graph:causal-project（fingerprint + counts）

reproject() -> 同上（幂等锚命中 → 零写入）

query_causal(effect_ref, *, include_conditions=True) -> CausalEdge 列表
    —— 只读；ORDER BY causal_edge_id（canonical）
```

## 4. Contract：KnowledgeHealthRuntime

```text
scan(*, actor_id) -> HealthReport
    output: {health_id, fingerprint, signals: {causal_conflict_density,
            temporal_decay_signal, orphan_assertion_count,
            hypothesis_staleness}, provenance_ref}
    存储: akb_health_signals（migration 16）
    failure: E-V09-HEALTH-INVALID（输入子面不可用——fail-closed）
    provenance: graph:health-scan

propose_maintenance(signal_ref, *, actor_id) -> MaintenanceTask
    —— system 只产提案；提案 = V0.8 VerificationTask（task_type 新增
       "maintenance_review"——生命周期零修改）；human 执行
    provenance: graph:maintenance-proposal
```

## 5. Contract：ConflictRuntime v2

```text
detect(*, actor_id) -> ConflictReport
    —— 在 CausalProjection 上检测：同 effect_ref 互斥机制/互斥条件
       （确定性检测算法——同投影同报告）
    output: {conflict_id, conflict_records[](effect_ref, mechanism_a,
             mechanism_b, assertion_refs, conflict_ref), provenance_ref}
    处置: flag 语义（V0.3 延续——标记不裁决，裁决 human）
    provenance: graph:conflict-detect-v2
```
