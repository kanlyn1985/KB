## Causal Model（边界五律实测锚定）

1. CausalRelation ≠ Assertion（投影全流程 akb_assertions unchanged）；
2. CausalProjection ≠ Graph Mutation（kg_nodes/kg_edges unchanged）；
3. Projection rebuildable（同快照+规格→同 projection_id/fingerprint）；
4. Unknown relation fail-close（白名单 causes/caused_by/enables/prevents）；
5. counterfactual = hypothesis 专属（未在本阶段实现，设计边界保留）。

## Health Governance

四信号（stability/verification/conflict/causal_coverage）只读聚合；
score 加权（0.3/0.3/0.2/0.2）+ healthy/watch/degraded 三态；
**system cannot modify knowledge automatically**——零 assertion/graph 写入实测，
MaintenanceTask 提案制属后续（V0.8 task 通道）。

## Conflict Detection

三型白名单 fail-close（ASSERTION_VALUE_CONFLICT / CAUSAL_MECHANISM_CONFLICT /
DOMAIN_SCOPE_CONFLICT）；CAUSAL_MECHANISM_CONFLICT 消费 CausalProjection
（condition-set-mutual-exclusion 确定性判定）；status 仅 open/reviewed/dismissed
——零 resolution/零 truth selection/零 mutation。

## Provenance

graph:causal-projection-create / graph:knowledge-health-create /
graph:conflict-detect（+ V0.8 九活动）全进 akb_provenance；seq 单调锚重放；
零第二套审计系统。

## Determinism Guarantees（FINAL 独立复算）

causal_id / snapshot_identity / health hash / conflict_id——同输入同输出、
差异输入异输出全部独立复算 PASS；canonical JSON 派生；零 timestamp/零 random/
零 runtime ordering 依赖。

## Migration Decision

**NO MIGRATION 维持**：migration chain [1..15] 零扩展；akb_causal_edges/
akb_health_signals/akb_conflicts 三表实测不存在（sqlite_master 验证）；
快照/provenance 模型足够。**未来触发条件**（出现任一则进新任务书评估）：
①历史趋势查询（health/conflict 信号时序对比）②大规模索引需求 ③跨进程分析。

## Governance Boundaries（五条直通禁令）

Hypothesis→Assertion / Verdict→Fact / Reasoning→Knowledge Mutation /
System→Governance / **CausalProjection→kg_* 直写**——全部禁令实测锚定。

## Known Limitations（P1，不阻断 freeze——缓解路径已定义）

1. **P1-01** causal edge scalability——内存投影随基数增长；缓解：migration 16
   触发条件已定义（大规模索引需求出现时）；
2. **P1-02** health historical trend——信号时序对比需历史消费方（migration 16
   联动）；
3. **P1-03** conflict precision——机制互斥判定当前为条件集合互斥，文本语义比对
   DEFERRED。
