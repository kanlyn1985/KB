AKB V0.9 Design Review Report — Causal Knowledge Layer & Knowledge Health Governance

Date: 2026-09-04 · Baseline: 0e49c3d（V0.8 FROZEN）· DESIGN ONLY · Decision: DESIGN COMPLETE

1. Executive Summary

核心设计判断：因果层值得成为下一层抽象——AKB 从"知识生命周期记录系统" 进入"知识结构理解系统"的路径不是继续增加 runtime，而是引入 Causal Knowledge Layer （Candidate A SELECTED）+ Knowledge Health Governance（Candidate C SELECTED）。 关键架构裁定：因果断言（内容）走 V0.4 既有 assertion 通道；因果结构（因→果→条件→ 机制图）以 CausalProjection 独立只读派生面存在（migration 16 append-only 两新表）； kg_* 零触碰；五条直通禁令（含新增 CausalProjection→kg_* 直写禁令）+ 4 条永久红线 （multi-agent/learning/LLM truth/直通）全部显式。Deterministic first / provenance first / governance first 三原则全延续。

7-9. Causal Model / Boundary 五律 / Architecture

因果边界五律：①CausalRelation ≠ Assertion（内容=assertion 通道；结构=独立投影） ②Causal hypothesis ≠ Fact（V0.8 通道零修改）③kg_* read-only 不变 ④Causal projection 可重建（fingerprint 锚，V0.5 先例）⑤counterfactual = hypothesis 专属。 架构图见 ARCHITECTURE §1——Ontology→Graph→Reasoning→Governance→Evolution 主轴 延续，CausalProjection/Health/Conflict v2/MaintenanceTask 为新增只读+提案层。

10-13. Contracts（四件）

CausalProjectionRuntime（project/reproject/query——fingerprint 确定性 + 幂等 锚 + fail-closed）· KnowledgeHealthRuntime（scan 四信号 + propose_maintenance—— system 只产提案）· ConflictRuntime v2（机制级冲突确定性检测 → flag 不裁决）· MaintenanceTask（V0.8 task 通道 task_type 扩展——生命周期零修改）。字段级定义见 ARCHITECTURE §3-§6。

14-17. Governance / Determinism / Provenance / Migration

Governance：五条直通禁令（Hypothesis→Assertion、Verdict→Fact、Reasoning→ Knowledge Mutation、System→Governance、+新增 CausalProjection→kg_* 直写）。 Determinism：同断言面同指纹/同投影同报告/同状态同提案集。Provenance：四新活动 命名空间（graph:causal-project/health-scan/maintenance-proposal/conflict-detect-v2） 复用 akb_provenance。Migration：migration 16（append-only：akb_causal_edges + akb_health_signals）——设计期明示理由（因果边基数 10^3-10^4 下 provenance-only JOIN 不可行，V0.8 P1-01 教训实测锚定）；rollback=drop 零数据损失；实现期保留 降级 NO-MIGRATION 决策点。
