## 规模（55）

| 组 | 数 | 内容 |
|---|---|---|
| positive | 20 | 同事实多证据（2/3/4 成员）、参数/约束/定义/测试/观测/时间区间/时序等句式族 |
| negative | 15 | 空集/重复成员/超限/缺 unit/缺 effective_at/孤儿 relation/malformed provider/未知策略/冲突爆炸/伪造多元素 run 等 |
| determinism | 5 | 双跑全等/逆序不变/簇序稳定/舍入一致/配置 hash 区分 |
| conflict | 5 | value/temporal/source/ontology/relation 各一（全溯源字段断言） |
| provider-boundary | 5 | 建议可用/裁决拒绝/malformed 拒绝/crash 隔离/actor 无特权 |
| provenance | 5 | 五级链完整/缺成员溯源 P0/trace 等价/多 segment 父级/审计自包含 |
