## 2. Root Cause（逐缺陷）

- A/E：V0.2 candidate_id 仅 run 内唯一（跨 unit 重名）——对齐层原实现 `u["unit_id"]`
  引用外层 for-unit 循环变量，在 relation 循环中失效（unit_id 全部串到最后一个 unit）；
- B：初版实现以最小可用路径交付 CMP-008 面但 state 簇为空占位——违反"不得以占位宣称 PASS"；
- C：L3 ontology_ref 是 TYPE 级引用（object_type:equipment）非实例唯一——作 union 键
  会让所有同 type 实体合并；且单键选择使"含 ref 的成员"与"仅 normalized_form 的成员"
  分裂；
- G：初版规则序 INVALID→CONFLICTING→COMPATIBLE 无 PARTIALLY 分层且无显式序声明；
- H：`len(anchored)==len(units) → same` 未比较锚值/区间关系；
- I：event 簇只按 event_time 分组。

## 3. Code Change（before → after）

| Defect | before | after |
|---|---|---|
| A/E | `s_cl = ec_index.get((u["unit_id"], r.get(...)))`（u 为外层循环变量） | relation record 自带 `unit_id`；`s_cl = ec_index.get((r["unit_id"], r.get(...)))`——零 ambient 依赖 |
| B | `result.state_clusters = []` | `_state_alignment()`：(subject_cluster, state predicate family, valid_time)；六种 alignment 值（aligned/contradictory/missing/partial-anchored…）；contradictory 窗 → contradictions[] |
| C | 单键 `{L1 or L3 or L4}` | 多键 union-find：L1 精确形 + L2 归一形（含尾部系动词剥离 L2b）+ L4 别名；L3 降权为审计快照（type 级不作 union 键）；entity_type 分歧 → IDENTITY_CONFLICT 源 |
| F | 无 STATE_CONFLICT | ConflictDetector 消费 alignment.state_contradictions → STATE_CONFLICT（detection_method=CONF-006-STATE，双方 sides 保留） |
| G | 隐式顺序 | 显式五级优先序 INVALID > CONFLICTING > PARTIALLY_COMPATIBLE > COMPATIBLE > INCOMPARABLE（COMPAT-002 规则号 + inputs/result 记录） |
| H | `len(anchored)==len(units) → same` | 六态真实判定：same（锚值全等）/overlapping（区间相交）/sequential（全隔）/missing（全缺）/unresolved（存在未解析）/partial（混合） |
| I | 仅 event_time 分组 | event_time 相等 AND 参与实体簇重叠 ≥1（并查合并；无重叠 → 独立事件） |
