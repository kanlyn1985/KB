5. State Machine

双轴：assertion_type（extracted/observed/asserted/inferred/hypothesized）× status（candidate/validated/asserted/disputed/rejected/deprecated）。
非法组合（全部 E-ILLEGAL-*）：直创 asserted；inferred→asserted；hypothesized→validated/asserted（须重分类）；validated→candidate；rejected→any；无审计行的 status 变更。
Evidence Gate：validated/asserted/disputed 必须 ≥1 evidence（DB CHECK + Validator 双层）。

6. Evidence Gate

candidate → validate → (no evidence → 保持 candidate / E-INV-001-NO-EVIDENCE) · (valid evidence → validated)。 validator hash 复核；observed 弱信号 confidence ≤0.75 规则保留。

7. Provenance

Provenance.trace(assertion_id)：Assertion → Evidence → Document → Source 四级链 + actor/activity/policy_version/occurred_at 历史；链断 → E-CHAIN-BROKEN（不静默）。 legacy resolver 仅解析（compatibility adapter，不产 Canonical 行）。

8. Graph Projection

PATH A（Migration Backfill）：legacy 边 → candidate 断言 → assertion_ref 回填（compatibility linkage）。
PATH B（Runtime Projection）：仅 validated/asserted 经 project_edge()；candidate/hypothesized/rejected/deprecated → 拒绝。
投影失败 → 事务回滚，Canonical 零变更（INV-006）。

9. Migration

迁移版本 10 经现有 SchemaMigrator（复用，未建第二套框架）。DRY-RUN 默认； 幂等（重跑 0 重复断言）；批事务 + resume；--verify 门禁（broken_refs=0 + INV-001/002 violations=0）。 上游遗漏修复：v9（phase9_scheduler_leadership）纳入 CORE_MIGRATIONS；PLATFORM_MIGRATIONS=CORE（消除 version 重复应用）。
