## 6-10. 边界与机制验证

- **Provider Boundary**：FakeSemanticCompilerProvider 换装测试通过；provider 只返回 RawExtraction；
  provider 崩溃 → run failed 零跨界写入（CMP-012/SC-039）；provider 无治理 API 访问面。
- **Determinism**：同输入双跑语义内容全等（排除 ID/审计字段）；候选 (span_start, normalized_form)
  稳定排序；CanonicalJSON fingerprint 同四元组逐字节相等（CMP-011/017）。
- **Idempotency**：UNIQUE(content_fingerprint) 数据层锚 + 幂等返回该 run 全部产物
  （units=完整 segment 集 + assertions 同集）；无第二 create_candidate（CMP-003/019）。
- **Provenance**：describe_run/trace_assertion_compilation 回答八问（CMP-009）；
  run 失败也留 provenance 痕（append-only 审计）。
- **Failure Isolation**：segment 级失败跳段 + warning；provider 级失败 run failed 零半成品；
  SAVEPOINT 原子回滚（CMP-012）。
- **Agent Write Boundary**：compiler 无 agent 写接口；V0.1 security_boundaries 静态审计保持 PASS。

## 12. Known Risks

1. BuiltinRuleExtractor R-01..R-06 对 OBC/DCDC 语料的召回率未经全语料量化（Golden 40 是首个锚点）；
2. compile() 单事务含全部 segment units——超长 Evidence 可能产生大事务（V0.2 单证据语义下可接受，
   batch 化时需分批事务）；
3. 幂等返回的 assertions 顺序依赖 LIKE 反查（source_unit_refs_json）——语义正确但非索引最优；
4. Semantica adapter 仍为 Protocol 位（V0.2 不实现，ADR-006 边界不变）。
