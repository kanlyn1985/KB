   仅内置 strict deterministic 规则引擎）；
2. 跨 run 推理链的祖先环检测在提案级为接口占位（migration 14 持久化后由
   trace service 祖先路径 seen 承担——RS-CMP-008/013 已覆盖递归环截断）；
3. RR-01 规则展开的语义域（satisfies_rule/rule_requires 谓词词汇）为最小内置集，
   DomainPack 扩展接口已留未实装；
4. akb_reasoning_runs 的 proposals_json 为提案快照（不含 provider 原始响应全文——
   LLM 接入时需扩展 raw response 审计）；
5. 治理复核聚合视图（inferred 队列仪表盘）未实装——治理走 akb_assertions 查询即可用。
