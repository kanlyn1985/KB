9-11. Reasoning Context / Rule / Inference Contract

ReasoningContext（context_id 确定性派生；graph_fingerprint 锚复用 V0.5）/ ReasoningRule（versioned；语义单一归属）/ InferenceCandidate（candidate ≠ 事实； candidate_id 确定性；inferred_candidate 状态）。字段级定义见 V0.6_REASONING_ARCHITECTURE_AND_CONTRACT.md。

12-15. Provenance / Determinism / Status / Temporal

五级 provenance 链（candidate→run→context→assertions→evidence→documents—— 零不可追溯输出）；deterministic first（禁 DB 行序/随机/时钟/LLM）；状态矩阵 （inferred≠validated；inferred→asserted 永久禁止延续；hypothesis≠inference； hypothesized 零进入）；temporal_context 只读引用 V0.3（A(T1)≠B(T2) 不自动构成 contradiction；temporal ambiguity fail-closed）。

16-18. Governance / LLM / DomainPack Boundary

Governance：Reasoning 只产 candidate，不 validate/approve/promote/merge； LLM：非正确性必需，未来仅 proposal 通道（同 governance 边界，非 truth/authority）； DomainPack：只实例化参数（词汇/约束只收紧），规则语义单一归属 Reasoner。

19-20. Migration Impact / Future Scope

NO MIGRATION（derivation_json 内扩展 context_id/graph_fingerprint—— 零新表）；V0.7+ hypothesis/planning/agent/LLM autonomous/分布式/向量全部 out of scope，provider 通道与 canonical JSON 字段为预留接口。
