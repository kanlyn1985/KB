## 1. V0.5 → V0.6 Change Control Matrix（按代码审计调整）

| Area | V0.5 状态 | V0.6 允许 |
|---|---|---|
| Evidence | frozen | consume only（只读） |
| Assertion semantics | frozen | consume only（candidate 通道复用 V0.4） |
| Graph nodes（6 类） | frozen | consume（只读 Q 面） |
| Graph edges（6 类） | frozen | consume（relates_to/supports/derived_from 参与推理；
  contradicts 仅 context 标注；validates/extracted_from 不参与） |

  全部确定性派生；零第二套 identity） |

  + derivation_json 扩展——JSON 内扩展不改表） |
| Query Q-01..06 | frozen | consume only（context builder 是 query 的调用方） |
| Reasoning | V0.4 foundation | extend（编排层 + 新 provider/rule_version；
  RR-01..04 frozen 语义零修改） |

  （零新治理动作；候选晋升走既有 human 通道） |
