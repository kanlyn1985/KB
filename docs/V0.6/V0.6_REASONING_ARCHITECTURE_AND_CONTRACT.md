## 2. Contract：ReasoningContext

| 字段 | 类型/派生 | 语义 |
|---|---|---|
| context_id | "grc_"+SHA256[:16] | 确定性 identity（§9.1 字段集） |
| root_entity | node_id | 推理起点 EntityNode |
| graph_fingerprint | 引用 kg_projection_runs | 输入子图锚（V0.5 锚复用） |
| input_nodes / input_edges | canonical 排序列表 | 选中子图（Q-02/Q-04 只读结果） |
| input_assertions | assertion_id 列表 | 最终推理输入（engine.reason 的 parents） |
| status_filter | {"valid","flagged"} | Q-05 语义（invalidated 需 audit 显式） |
| temporal_context | V0.3 scope 只读引用 | 时间窗前提 |
| query_constraints | hops/depth/谓词白名单/规则白名单 | 展开控制 |
| version | rule_set_version + domain_pack_version | 版本组合 |

## 3. Contract：ReasoningRule

```text
rule_id          稳定标识（RR-01..04 沿用 V0.4；新规则新 id）
rule_version     语义变更即递增
rule_type        deduction|transitive|corroboration|contradiction_flag|domain_<id>
input_pattern    断言形态模板（subject_ref/predicate_ref/object + temporal 约束）
output_pattern   候选形态
constraints      {require_evidence: true, max_expansion: 256, temporal_window: ...}
```

不变量：rule 语义单一归属（DomainPack 只实例化参数）；frozen RR-01..04 语义零修改。

## 4. Contract：InferenceCandidate

字段集见 V0.6_DESIGN §3.3。行为契约：
- identity：candidate_id = 确定性派生（同输入同 id）；
- output：candidate 状态恒 "inferred_candidate"；
- 输出面：进 V0.4 create_candidate（inferred）或作为结果返回（不落库为事实）；
- status：任何后续晋升走 V0.4 governance（human）。

## 5. Contract：ReasoningRun / ReasoningResult

- ReasoningRun = V0.4 akb_reasoning_runs 行复用（derivation_json 扩展
  context_id/graph_fingerprint——零新表）；
- ReasoningResult = {run_id, context_id, candidates, warnings, errors, fingerprint,
  status(completed|partial|failed)}——与 V0.4 reason() 返回面同构；
- fingerprint = SHA256(canonical_json({context_id, rule_set_version,
  rule_version, parent_assertions sorted}))——幂等重放锚。

## 6. input/output/identity/provenance/determinism/failure/status/version 汇总

| Contract | input | output | identity | provenance | determinism | failure | status | version |
|---|---|---|---|---|---|---|---|---|
| ReasoningContext | root+constraints | 选中子图+断言集 | context_id | graph_fingerprint | 确定性派生 | 缺级 error | status_filter 生效 | 组合版本 |
| ReasoningRule | 断言形态 | 候选形态 | rule_id+version | — | 语义冻结于版本 | 不匹配 skip | — | 必须显式 |
| InferenceCandidate | context+rule+parents | conclusion 候选 | candidate_id | 全链引用 | 同输入同集 | 缺 provenance 拒绝 | inferred_candidate | rule_version |
| ReasoningRun | context | result | run fingerprint | akb_reasoning_runs+provenance | 幂等重放 | run failed | running/completed/partial/failed | rule_set |
| ReasoningResult | run | candidates+warnings+errors | run_id | 全链 | 确定性 | errors 分类 §9 | 同 run | 同 run |
