1. 目的与系统愿景

本系统旨在构建一个面向 Agent 的可信、可追溯、可推理、可持续演化的知识基础设施。它不是简单的 RAG、知识图谱、文档库或 Agent Memory，而是连接外部世界、知识模型、世界模型与 Agent Runtime 的中间层。

1.1 核心使命

External Reality → Source / Observation → Evidence → Knowledge Assertion → Semantic World Model → Retrieval / Reasoning / Context → Agent Decision → Action / Observation → State / Memory / Knowledge Update

1.2 核心设计原则

原则规范要求
Evidence First任何被系统声明为已证实/已断言的知识必须可以追溯到证据。
Assertion FirstKnowledge 的 Canonical Truth Unit 为 Assertion，而不是 Graph Edge 或 Vector Chunk。
Graph as ProjectionGraph 是知识断言的语义投影/运行时视图，不是唯一真相源。
Asserted ≠ Derived验证知识与推理知识必须严格区分。
Time as First-Class有效时间、观察时间、系统记录时间必须可区分。
Deterministic BoundaryLLM/NLP 可以提出候选知识，但不得静默绕过验证门禁。
Provider Neutral向量、图、解析器、推理器和连接器必须通过稳定接口可替换。
Testability知识正确性、软件正确性和 Agent 行为正确性均必须可测试。

5. 核心系统需求

编号优先级需求验收
SYS-EVD-001P0系统必须保存来源、位置、时间和内容完整性信息，形成可定位 Evidence。任一 Evidence 可回溯 Source/Document。
SYS-AST-001P0知识必须以 KnowledgeAssertion 为 Canonical Unit。核心查询、存储、推理和审计均可用 assertion_id 定位。
SYS-AST-002P0Validated/Asserted Assertion 必须具备有效 Evidence Reference。无 Evidence 的 asserted assertion 必须拒绝。
SYS-SEM-001P0系统必须支持 Entity、Relation、Event、State 的语义模型。对象创建、查询、关联和 provenance 全通过。
SYS-GRAPH-001P0Graph 必须是 Assertion 的可追踪 Projection。任一 edge 可反查 assertion。
SYS-REASON-001P1Reasoning 必须输出 Derived Assertion 和 proof trace。derived assertion 具备 parent/rule/reasoner。
SYS-RET-001P1支持 lexical/vector/graph 多通道检索及统一 Planner。三通道可独立执行并可组合。
SYS-CTX-001P0AgentContext 必须同时承载 knowledge、evidence、state、memory、constraints、uncertainty。Context contract 通过。
SYS-AGENT-001P1Agent Action 必须经过 policy/permission gate。越权 action 被拒绝。
SYS-OBS-001P1Observation 必须能关联 Action、Episode 和 State Update。E2E loop 通过。

7. Assertion 生命周期

candidate → validated → asserted → disputed / deprecated
candidate → rejected
asserted + rule → inferred (Derived Assertion)

所有状态迁移必须记录 actor、时间、原因、policy_version 和 provenance。禁止任意状态跳转。

9. Failure / Recovery Requirements

故障必须行为禁止行为
Parser 失败保留失败状态与 source reference，支持重试生成缺失内容 Document
Embedding 不可用允许 lexical/graph fallback 并标记 degraded伪造 embedding
Graph 不可用Canonical 继续可读，Graph 可重建把 Graph 当 Canonical truth
Reasoner 超时返回 timeout/partial 与 trace把未完成推理当完成
重复入库按 identity 幂等处理产生不可区分重复知识
恢复先恢复 Canonical，再重建 Projection用 Index 恢复 Canonical

10. Performance Measurement Baseline

指标要求
Retrieval latency记录 P50/P95/P99，并按 lexical/vector/graph/fusion 分桶。
Context latency包含 retrieval、evidence gate 和 serialization。
Ingestion throughput记录 document/hour 与 MB/min。
Reasoning latency按 rule count、graph depth、assertion count 分桶。
Concurrency至少覆盖 1/5/10/25/50 并发。
