Agentic Knowledge Base 系统需求规格说明书 V1.0

文档编号：AKB-SRS-001　版本：V1.0　日期：2026-08-31

1. 目的

定义一个面向 Agent 的可信、可追溯、可推理、可持续演化的知识基础设施。系统不是单纯RAG、知识图谱或Memory，而是连接外部世界、知识模型、运行时与Agent的中间层。

2. 核心原则

原则要求
Evidence FirstAsserted/Validated Knowledge必须可追溯到Evidence。
Assertion FirstKnowledge的Canonical Unit为Assertion。
Graph as ProjectionGraph是Knowledge Assertion的语义投影，不是唯一真相源。
Asserted ≠ Derived验证知识与推理知识必须区分。
Time First-Class有效时间、观察时间、记录时间必须区分。
Provider NeutralGraph、Vector、Parser、Reasoner、Connector均通过接口可替换。

4. Canonical Data Objects

DomainObjects
EvidenceSource, Document, Evidence, SemanticUnit
KnowledgeAssertion, Entity, Relation, Event, State
CognitiveContext, Memory, ReasoningTrace
AgentGoal, Plan, Decision, Action, Observation

5. Knowledge Lifecycle

Source → Document → Evidence → SemanticUnit → Candidate Assertion
→ Validation → Asserted Knowledge → Semantic Projection → Graph
→ Reasoning → Derived Assertion → Context → Decision → Agent

6. System Requirements

IDRequirement
SYS-EVD-001系统必须生成可定位、可追溯的Evidence。
SYS-AST-001系统必须以Assertion作为Canonical Knowledge Unit。
SYS-AST-002无有效Evidence的Assertion不得晋升为Asserted Knowledge。
SYS-SEM-001必须支持Entity、Relation、Event、State。
SYS-GRAPH-001Graph Edge必须能够反查Assertion。
SYS-REASON-001Reasoning必须输出Derived Assertion及推理链。
SYS-RET-001必须支持Lexical、Vector、Graph等检索通道。
SYS-CTX-001Context必须能够承载Knowledge、Evidence、State、Memory、Constraints与Uncertainty。
SYS-AGENT-001Agent Action必须经过Policy与Permission控制。

7. 核心不变量

IDInvariant
INV-001No Evidence → No Asserted Knowledge
INV-002Derived Knowledge ≠ Asserted Knowledge
INV-003Graph Edge → Assertion可追溯
INV-004Assertion → Evidence可追溯
INV-005Canonical Knowledge不得被Index反向修改
INV-006Agent不得直接修改Authoritative Knowledge

8. V模型

Requirements → Architecture → Design → Implementation
                                             ↑
Acceptance ← System Test ← Integration ← Unit Test

9. 验证

系统必须同时建立软件V与知识V。知识V至少覆盖Evidence、Assertion、Ontology、Graph、Retrieval、Reasoning、Answer/Decision。
