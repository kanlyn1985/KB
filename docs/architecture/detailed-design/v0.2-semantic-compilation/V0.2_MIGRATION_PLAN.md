## Migration 12（v02_semantic_compilation，设计）

### new columns（1 表）
```sql
ALTER TABLE akb_semantic_units ADD COLUMN provenance_ref TEXT REFERENCES akb_provenance(provenance_id);
ALTER TABLE akb_semantic_units ADD COLUMN compiler_run_ref TEXT;
ALTER TABLE akb_semantic_units ADD COLUMN configuration_hash TEXT NOT NULL DEFAULT '';
ALTER TABLE akb_semantic_units ADD COLUMN content_fingerprint TEXT;
CREATE UNIQUE INDEX IF NOT EXISTS ux_akb_su_fingerprint ON akb_semantic_units(content_fingerprint);
```
论证：provenance_ref/compiler_run_ref 是任务书 §7/§14 要求的审计链字段；
configuration_hash+fingerprint 是 §16 幂等机制的数据层锚点；四列均不可从既有列推导。
UNIQUE 索引允许 NULL（存量行不受影响）。

### new table（1 张）
```sql
CREATE TABLE IF NOT EXISTS akb_compilation_runs (
    run_id             TEXT PRIMARY KEY,
    evidence_ids_json  TEXT NOT NULL DEFAULT '[]',  -- V0.2 恰含一个元素 ["<evidence_id>"]（Repair B；batch=V0.3+）
    compiler_version   TEXT NOT NULL,
    configuration_hash TEXT NOT NULL,
    ontology_version   TEXT,
    provider_id        TEXT NOT NULL,
    actor_id           TEXT NOT NULL,
    policy_version     TEXT NOT NULL,
    status             TEXT NOT NULL CHECK (status IN ('running','completed','failed','partial')),
    warnings_json      TEXT NOT NULL DEFAULT '[]',
    created_at         TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%SZ','now')),
    finished_at        TEXT
);
```
论证：provenance 表粒度是单次治理动作；run 是聚合实体（一批 evidence × 一次配置），
回答任务书 §14 八问的最小充分结构。

### new indexes
`ix_akb_runs_status (status)`；units 四列随用例按需（fingerprint UNIQUE 已建）。

### constraints
runs.status CHECK；units.fingerprint UNIQUE；**零删除/零改写既有列**。

### backfill
存量 akb_semantic_units（V0.1 迁移期产的编译影子数据——当前为空表或影子行）：
provenance_ref/compiler_run_ref = NULL（合法，无 run 语义）；configuration_hash=''；
fingerprint=NULL（不参与 UNIQUE）。**不重算历史**（历史 unit 非本次编译产物）。

### rollback
新增列/表 DROP 即回滚（只被 V0.2 写入）；无既有数据破坏面；备份先行（BackupManager.snapshot）。

### dry-run / idempotency / production safety
- 迁移工具复用 evidence_core/migration 模式（DRY-RUN 默认 + --apply + --verify）；
- fingerprint 列语义：CanonicalJSON 构造（DETERMINISM_SPEC 正式定义，fingerprint_spec=v1）；
- 无 new migration executable 于本设计任务（执行另行任务）；

- 语句全部 IF NOT EXISTS / 列存在性检查 → 幂等；
- 生产执行条件：架构负责人批准 + 备份 + 生产无活跃写窗口（与 V0.1 回填同窗）。
