# V0.2 Determinism Spec

- Document ID: AKB-DD-V02-008 · Status: Ready for Implementation

## 两级确定性（禁止混淆）

| 级别 | 定义 | 适用 |
|---|---|---|
| strict deterministic | 同 Evidence + 同 compiler_version + 同 configuration_hash → 输出逐字节可复现 | L1/L2/L4/L5/L6/L7/L8 + 内置规则 extractor |
| provider stochastic but traceable | 输出不可逐字节复现，但输入/输出/版本/参数全部留痕，可审计不可复现的原因 | SemanticCompilerProvider（LLM 等）——输出仍受 schema validation 约束 |

## Deterministic 要素清单

D-01 JSON canonicalization：`json.dumps(sort_keys=True, ensure_ascii=False, separators=(',',':'))`（V0.1 models 同款）；
D-02 候选排序：EntityCandidate 按 (span_start, normalized_form)；RelationCandidate 按 (subject_id, predicate, object_id)——禁止依赖 dict/set 迭代序；
D-03 confidence 舍入：round(x, 4)（存 4 位小数，比较用舍入后值）；
D-04 时间戳：语义字段（event_time 等）用锚定时间（T-02），**审计字段**（created_at/occurred_at）允许真实时钟——二者分离，determinism 对比时排除审计字段；
D-05 随机种子：V0.2 内置组件禁止随机；provider 侧 seed 必须记录（configuration_hash 组成部分）；
D-06 provider non-determinism：temperature/top_p/模型版本进 configuration_hash；provider 输出 hash 记录于 run；
D-07 配置哈希：configuration_hash = sha256(canonical_json(config))，config 含 provider 参数/规则版本/阈值/DomainPack 版本。

## Idempotency（任务书 §16）

CompilationFingerprint = sha256(evidence_id + compiler_version + configuration_hash + content_hash)。

- `akb_semantic_units.content_fingerprint` UNIQUE 约束（migration 12）；
- 重复 compile（同 fingerprint）→ 返回既有 SemanticUnit + 关联既有 candidate assertions，
  不产生第二份 unit/assertion（E-COMPILATION-DUPLICATE 语义=幂等返回，不是错误抛出）；
- 不同 compiler_version / configuration → 新 fingerprint → 新 unit（CMP-004 可区分）；
- 断言幂等联动：fingerprint 命中时不调 create_candidate（断言侧由 unit 关联回查）。
