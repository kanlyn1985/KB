# V0.2 Data Flow

- Document ID: AKB-DD-V02-002 · Status: Ready for Implementation

## 1. 端到端流（对象级）

```text
[akb_evidence e]  (immutable, V0.1)
      │  SemanticCompiler.compile(evidence_id, config)
      ▼
[CompilationRun]  (run 级：compiler_version/configuration_hash/ontology_version/provider/actor/policy)
      │
      ▼
[Preprocessor]     e.content ──> segments[]（分段，不改原文）
      ▼
[Normalizer]       segment ──> normalized_text（规则集 N-01..N-08）
      ▼
[Semantic Extractor]  normalized_text ──> raw extractions（entities/relations/temporal 表达）
      ▼                （provider 侧：deterministic 规则 or SemanticCompilerProvider）
[Entity Candidate Resolver]  surface_form ──> EntityCandidate[]（candidate，非 authoritative）
      ▼
[Relation Candidate Resolver]  (subj,pred,obj) candidates ──> RelationCandidate[]
      ▼
[Temporal Parser]  时间表达 ──> TemporalParse（5 类时间不合并）
      ▼
[Ontology Mapper]  surface concept ──> OntologyMapping（默认 candidate）
      ▼
[SemanticUnit]  （组装 + provenance_ref + compiler_run_ref + fingerprint）
      ▼
[CandidateAssertionBuilder]  SemanticUnit ──> KnowledgeAssertion(status=candidate)
      ▼                                  （经 AssertionStore.create_candidate，INV-001/002 生效）
[V0.1 治理链]  validate → promote → project
```

## 2. 层间数据契约（类型签名）

| 层 | input | output | 失败行为 |
|---|---|---|---|
| Preprocessor | `EvidenceRecord` | `list[TextSegment]`（span 保留） | E-COMPILER-INVALID-EVIDENCE（空/超长） |
| Normalizer | `TextSegment` | `NormalizedSegment` | E-NORMALIZATION-FAILED（规则异常，segment 级隔离） |
| Semantic Extractor | `NormalizedSegment` | `RawExtraction` | E-SEMANTIC-EXTRACTION-FAILED（provider 错误→run 级隔离） |
| Entity Resolver | `RawExtraction` | `list[EntityCandidate]` | 候选级失败丢弃该候选（记录 warnings） |
| Relation Resolver | 同上 | `list[RelationCandidate]` | 同上 |
| Temporal Parser | 同上 | `TemporalParse \| None` | None（无时间语义合法） |
| Ontology Mapper | candidates | `list[OntologyMapping]` | unknown concept → quarantine（E-ONTOLOGY-MAPPING-FAILED 记录，不产 assertion） |
| Assertion Builder | `SemanticUnit` | `KnowledgeAssertion(candidate)` | E-CANDIDATE-BUILD-FAILED |

## 3. 对象不可变性与生命周期

```text
Evidence（immutable，V0.1）
SemanticUnit（immutable——创建后不修改；重编译产生新 unit（fingerprint 区分））
EntityCandidate/RelationCandidate/TemporalParse/OntologyMapping（SemanticUnit 内嵌 JSON，随 unit immutable）
CompilationRun（immutable 审计实体）
KnowledgeAssertion(status=candidate)（进入 V0.1 治理链，此后生命周期归 V0.1）
```

## 4. 与 V0.1 治理链的接缝（唯一合法入口）

Candidate Assertion Builder 调用 `AssertionStore.create_candidate()`——INV-001/002/状态机/审计
全部在接缝处生效。Compiler 不直接写 akb_assertions（SQL 层直写会被 V0.1 触发器拦：
asserted 直创禁止；candidate 创建无 transitions 行约束，但 provenance 必须存在——由 create_candidate 保证）。

## 5. 失败传播与隔离

- segment 级失败：跳过该 segment，run 记 warnings（其余 segment 继续）；
- provider 级失败：run 标记 failed，已产出的 SemanticUnit 保留（有完整 provenance），不产 assertion；
- ontology quarantine：unknown concept 的 unit 照常落库（semantic_units），不产 assertion；
  quarantine 记录进 run.warnings——治理人工复核入口（V0.2-CMP-014）。
