# V0.2 Entity / Relation Extraction Spec

- Document ID: AKB-DD-V02-005 · Status: Ready for Implementation

## EntityCandidate（候选实体——非 authoritative）

| 字段 | 类型 | 说明 |
|---|---|---|
| candidate_id | str | run 内唯一（`ec_{seq:04d}`，稳定序号） |
| surface_form | str | 原文表面形 |
| normalized_form | str | N-04/05/06 归一形 |
| entity_type | str | equipment/parameter/state/event/document_ref/…（DomainPack.object_types 优先，fallback=unknown） |
| confidence | float | ∈[0,1]，deterministic 内置=规则命中强度；provider=其输出 |
| source_span | (start,end) | 原文坐标（可回放） |
| ontology_hint | str \| None | DomainPack 匹配 hint（candidate） |

**语义红线：Candidate Entity ≠ authoritative Entity。** Canonical entity registry 属后续治理产物；
V0.2 只产候选，entity 合并/晋升是治理流程（人工 or 后续版本治理接口）。

## RelationCandidate（候选关系——非 canonical Relation/Assertion）

| 字段 | 类型 | 说明 |
|---|---|---|
| relation_candidate_id | str | run 内唯一（`rc_{seq:04d}`） |
| subject_candidate_id | str | →EntityCandidate.candidate_id（无孤儿） |
| predicate_candidate | str | 规范化谓词（has_parameter/satisfies/constrained_by/measures/…；DomainPack.relation_types 优先） |
| object_candidate_id | str | →EntityCandidate.candidate_id |
| confidence | float | ∈[0,1] |
| source_span | (start,end) | 谓词命中处原文坐标 |
| ontology_hint | str \| None | candidate |

## 抽取规则（deterministic 内置 extractor，V0.2 默认 provider）

R-01 参数关系：`<entity> <单位数值> <unit>`（N-05/06 归一后）→ has_parameter
R-02 约束关系：`不超过|不大于|≤|至少|≥ <数值><单位>` → constrained_by（方向保留在 object 语义）
R-03 定义关系：`<X>是指|定义为|包括` → defined_as
R-04 测试关系：`<test_method> 测试|验证 <entity>` → verified_by
R-05 条件关系：`当|在<条件>下` → conditional_on（条件进 temporal_parse.conditions）
R-06 观测关系：测试结果句（classify_source_unit=test_result）→ observed 关系族
说明：R-01..R-06 是 V0.2 内置 provider 的最小规则集（从 facts.py 正则经验移植并泛化）；
DomainPack 可补充领域规则（版本化）；LLM provider 输出同 schema（经 §18 LLM 边界）。
