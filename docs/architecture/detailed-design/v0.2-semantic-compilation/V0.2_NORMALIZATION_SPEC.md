# V0.2 Normalization Spec

- Document ID: AKB-DD-V02-004 · Status: Ready for Implementation
- 铁律：Evidence.content immutable——normalization 结果只存 SemanticUnit.normalized_text。

规则集（执行顺序固定，rules_applied 逐条记录）：

| # | 规则 | 内容 |
|---|---|---|
| N-01 | Unicode 归一 | NFC（不改变语义内容，跨平台一致） |
| N-02 | Whitespace 归一 | 连续空白→单空格；行尾空白删除；段内换行→空格 |
| N-03 | 控制字符清除 | 保留 \n 分段语义（Preprocessor 已分段，此处段内清除） |
| N-04 | 标点归一 | 全角→半角（，→, 等）；引号归一双直引号 |
| N-05 | 数值归一 | 千分位逗号去除；全角数字→半角；科学计数法规范化（1×10³→1e3）；保留原始精度（不四舍五入数值本身） |
| N-06 | 单位归一 | 单位符号映射表（Ω→ohm、µF→uF、V/A/W 保持）；大小写敏感单位保持（mV≠MV）；SI 前缀不换算（保留原量纲，换算属治理语义） |
| N-07 | 日期时间归一 | ISO-8601 规范形（2026年9月1日→2026-09-01）；相对表达保留原文并标记 unresolved（由 Temporal Parser 锚定） |
| N-08 | 领域记号 | DomainPack.notational_rules（可配置，版本化；无 pack 时跳过） |

禁止项：不得做同义词替换（属治理语义）；不得做大小写折叠（单位/型号大小写敏感）；
不得截断；不得改变数值精度。

round-trip 承诺：normalized_text 可追溯到原 span（span 坐标保存于 candidate），审计可回放。
