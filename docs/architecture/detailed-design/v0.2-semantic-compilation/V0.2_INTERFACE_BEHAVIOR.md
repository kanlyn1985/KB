# V0.2 Interface Behavior

- Document ID: AKB-DD-V02-010 · Status: Ready for Implementation
- 位置：`agent_kb.evidence_core.compilation`（不建第二套 storage/framework）

## 1. SemanticCompilerProvider（Protocol，provider 边界）

```python
class SemanticCompilerProvider(Protocol):
    def provider_id(self) -> str: ...                 # 'builtin-rules-v1' / 'semantica-x' / 'llm-yyy'
    def extract(self, normalized: NormalizedSegment) -> RawExtraction: ...
```

- 内置默认实现：`BuiltinRuleExtractor`（strict deterministic，R-01..R-06）；
- LLM/Semantica 等任何 provider 只实现本 Protocol；输出必须过 `validate_raw_extraction(schema)`；
  malformed → E-SEMANTIC-EXTRACTION-FAILED（CMP-013）；
- **禁止**：provider 接触 akb_assertions/治理接口；provider 语义 = 产 raw extraction 候选。

## 2. SemanticNormalizer
`normalize(segment: TextSegment) -> NormalizedSegment`（N-01..N-08 顺序执行，strict）；
异常 → E-NORMALIZATION-FAILED。属性：纯函数。

## 3. Entity/Relation Candidate Resolver
`resolve_entities(raw) -> list[EntityCandidate]` / `resolve_relations(raw, entities) -> list[RelationCandidate]`
（稳定排序、无孤儿引用，违规 → E-CANDIDATE-BUILD-FAILED）。

## 4. TemporalParser
`parse(expressions, anchors) -> TemporalParse | None`（anchors=document/observation 时间；
当前时钟禁用）。unresolved 合法。

## 5. OntologyMapper
`map(candidates, domain_pack) -> list[OntologyMapping]`；unknown → quarantined；
**只读** DomainPack。

## 6. CandidateAssertionBuilder
`build(unit, store: AssertionStore, provenance: Provenance) -> KnowledgeAssertion | None`
- 必须 `store.create_candidate(...)`（唯一合法入口；直写 assertions 触发器拦截）；
- inferred → derivation 必填校验（E-CANDIDATE-BUILD-FAILED）；
- quarantined mapping 存在 → 不构建（返回 None + run warning）；
- 输出恒为 status=candidate（CMP-006）。

## 7. SemanticCompiler（编排器）
`compile(evidence_id, config, store, provenance, connection) -> CompilationResult`
- 幂等：fingerprint 命中 → 返回既有（E-COMPILATION-DUPLICATE 语义）；
- 建 CompilationRun（provenance activity=compile，policy_version='policy:v0.2'）；
- 8 层顺序执行，错误按 ERROR MODEL 隔离；
- 返回 `{run, units[], assertions[], warnings[], fingerprint, idempotent_hit: bool}`。

## 9. 通用契约

- authorization：actor_id 前缀同 V0.1（human:/system:/llm:——llm: 允许为 provider 侧 actor，
  仅能触发 compilation，不能治理）；
- audit：CompilationRun + provenance(activity=compile) + SemanticUnit 三层留痕；
- transaction：run 单事务（units+assertions+run 记录原子；幂等重入安全）；
- agent boundary：Agent Runtime 无 compilation 写接口（仅可读 run 结果——与 V0.1 一致）。
