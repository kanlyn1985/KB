# V0.2 Error Model

- Document ID: AKB-DD-V02-009 · Status: Ready for Implementation

## 错误码族

| 错误码 | 层 | 触发 | 隔离粒度 |
|---|---|---|---|
| E-COMPILER-INVALID-EVIDENCE | L1 | content 空/类型非法 | run failed |
| E-NORMALIZATION-FAILED | L2 | 规则执行异常 | segment 跳过 + warning |
| E-SEMANTIC-EXTRACTION-FAILED | L3 | provider 异常/输出 schema 不合格 | run failed（CMP-013 malformed rejection） |
| E-ONTOLOGY-MAPPING-FAILED | L7 | unknown ontology ref | candidate quarantine（unit 保留，assertion 不产——CMP-014） |
| E-CANDIDATE-BUILD-FAILED | L8 | derived 缺 derivation/结构非法 | unit 保留，assertion 不产 |
| E-COMPILATION-NONDETERMINISTIC | 编排 | 同 run 两次内部重放结果不一致（debug 模式校验） | run failed |
| E-COMPILATION-DUPLICATE | 编排 | fingerprint 命中 | **幂等返回既有产物**（非错误） |
| E-COMPILATION-PROVENANCE-MISSING | 编排 | run/provenance 行缺失 | run failed（P0——provenance 完整性 CMP-009） |

## 失败不越界承诺（任务书 §17）

任何错误路径下：
1. Evidence 零修改（append-only 触发器物理强制）；
2. authoritative Assertion 零修改（V0.1 受控更新触发器）；
3. Evidence Gate 不绕过（candidate 经 create_candidate，治理在 V0.1）；
4. Provenance 不绕过（run 失败也写 provenance(activity=compile, metadata={status: failed})）。

## 恢复语义

- run failed 后可重试（新 run，同 fingerprint 若配置未变则命中幂等）；
- quarantine 队列可人工复核后重跑（DomainPack 更新 → 新 configuration_hash）；
- 无自动重试上限（run 级幂等保证无限安全重试）。
