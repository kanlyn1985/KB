# V0.2 Temporal Semantics Spec

- Document ID: AKB-DD-V02-006 · Status: Ready for Implementation
- 铁律：五类时间不合并（任务书 §10）；禁止"全部压成一个 timestamp"。

## TemporalParse 结构

| 字段 | 语义 | 来源锚点 |
|---|---|---|
| event_time | 事件发生时间（过去事件） | 文本表达 + 锚定 |
| valid_time | 事实有效区间 {valid_from?, valid_until?} | 生效期表达（"自…起有效"） |
| observation_time | 观察时间 | evidence.observed_at（V0.1） |
| document_effective_time | 文档生效时间 | document.effective_at（V0.1） |
| ingestion_time | 摄入时间 | evidence.created_at（V0.1） |
| conditions | 条件上下文列表 | R-05 条件关系（"当…时"） |
| parse_status | resolved \| unresolved \| failed | 解析结果状态 |

## 规则

T-01 绝对日期 → ISO-8601（event_time/valid_time）；
T-02 相对表达（"发布之日起"/"上一年度"）→ 以 document_effective_time 为锚（**禁止用当前时钟**——破坏确定性）；
T-03 有效期表达（"有效至"/"自…起"）→ valid_time 区间（开/闭端按原文保留 raw）；
T-04 版本语义（"取代"/"修订"）→ 记入 conditions（supersedes 表达），处理归治理链（INV-005 历史 integrity）；
T-05 未来条件（"当…时将"）→ conditions + parse_status=unresolved（不猜测未来时间）；
T-06 无时间表达 → TemporalParse=None（合法，assertion.temporal_scope 置空）。
