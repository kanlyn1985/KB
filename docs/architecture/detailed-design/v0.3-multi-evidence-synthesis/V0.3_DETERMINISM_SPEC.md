# V0.3 Determinism Spec

- Document ID: AKB-DD-V03-012 · Status: Design Baseline

## 两级确定性（V0.2 延续，禁止混淆）

strict deterministic：同成员集+同 synthesis_version+同 configuration → 产物全等（排除审计字段）。
provider stochastic but traceable：同语义输入+同 provider metadata → 可追溯不必逐字节相等。

## 强制清单

D-01 成员序 canonical：evidence_id 字典序（[A,B]==[B,A]）——输入排序即冻结；
D-02 簇编号稳定：按簇内最小 (evidence_id, candidate_id)；
D-03 候选排序：(subject_ref, predicate_ref, object 值) 字典序；
D-04 JSON canonicalization：V0.1 同款 dumps（sort_keys/ensure_ascii=False/紧凑分隔符）；
D-05 置信度 round 4；
D-06 时间锚定禁当前时钟（审计字段除外，且不入语义/指纹）；
D-07 configuration_hash 含：synthesis_version/weight_policy/对齐规则版本/MAX_CONFLICTS/
     provider 参数（seed 等）；
D-08 禁 set/dict 迭代序影响语义输出（全部遍历经排序键）；
D-09 SynthesisFingerprint = SHA256(CanonicalJSON({set_fingerprint, synthesis_version,
     configuration_hash}))——同 Set+同版本+同配置 → 同指纹（REQ-017 前提）。

## 验证锚点

V03-CMP-002（顺序不变性）/ CMP-018（同输入双跑全等）/ CMP-025（trace 确定性）。
