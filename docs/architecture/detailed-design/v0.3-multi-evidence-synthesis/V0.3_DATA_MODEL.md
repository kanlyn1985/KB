# V0.3 Data Model

- Document ID: AKB-DD-V03-002 · Status: Design Only（migration 13 不执行）
- 默认规则：**prefer extension over duplication**——Evidence/SemanticUnit/KnowledgeAssertion/
  Document/Source 零并行副本。

## 1. 为什么必须新表（逐条论证）

| 提议 | 是否已有载体？ | 结论 |
|---|---|---|
| EvidenceSet 身份+成员清单 | akb_compilation_runs.evidence_ids_json 是**单证据 run 的恰一元素**语义（V0.2 定案），复用会破坏 CMP-019/022 基数契约 | **新表 akb_evidence_sets** |
| SynthesisRun 聚合 | akb_compilation_runs 语义=compilation（compiler_version/provider 等字段）≠synthesis（对齐/冲突/权重） | **新表 akb_synthesis_runs** |
| 成员清单 link 表 | Set 成员 ≤32、无独立生命周期、无反向查询需求 | 嵌入行 JSON（不建表） |
| 对齐/冲突/权重 | 计算中间物+审计快照（无跨 run 复用语义） | run 行 JSON 列（不建表） |
| SynthesisCandidate | 经 create_candidate 后即 KnowledgeAssertion | 无独立持久化 |
| SynthesisProvenance | akb_provenance 加 activity=synthesize 枚举值即可 | 复用 |
| SourceWeight | 随 run JSON + 策略版本化 | 不建表 |

## 2. Migration 13（v03_multi_evidence_synthesis，设计）

### 新表 2 张
```sql
CREATE TABLE IF NOT EXISTS akb_evidence_sets (
    set_id             TEXT PRIMARY KEY,          -- 'set_' + fingerprint 前 24
    members_json       TEXT NOT NULL,             -- canonical 排序 evidence_id 数组
    set_fingerprint    TEXT NOT NULL,             -- SHA256(CanonicalJSON({members,version,cfg}))
    synthesis_version  TEXT NOT NULL,
    configuration_hash TEXT NOT NULL,
    actor_id           TEXT NOT NULL,
    created_at         TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%SZ','now'))
);
CREATE UNIQUE INDEX IF NOT EXISTS ux_akb_sets_fingerprint ON akb_evidence_sets(set_fingerprint);

CREATE TABLE IF NOT EXISTS akb_synthesis_runs (
    run_id             TEXT PRIMARY KEY,
    set_id             TEXT NOT NULL REFERENCES akb_evidence_sets(set_id),
    members_json       TEXT NOT NULL,             -- 冗余快照（审计自包含）
    synthesis_version  TEXT NOT NULL,
    configuration_hash TEXT NOT NULL,
    provider_id        TEXT NOT NULL,
    actor_id           TEXT NOT NULL,
    policy_version     TEXT NOT NULL,
    status             TEXT NOT NULL CHECK (status IN
                        ('running','completed','failed','partial','capped')),
    alignment_json     TEXT,                      -- 对齐快照（derived）
    conflicts_json     TEXT,                      -- ConflictSet 快照
    weights_json       TEXT,                      -- SourceWeight 快照
    fingerprint        TEXT,                      -- 合成指纹（锚：status=completed 且首个成功产物 run）
    warnings_json      TEXT NOT NULL DEFAULT '[]',
    created_at         TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%SZ','now')),
    finished_at        TEXT
);
CREATE INDEX IF NOT EXISTS ix_akb_synruns_status ON akb_synthesis_runs(status);
CREATE UNIQUE INDEX IF NOT EXISTS ux_akb_synruns_fingerprint ON akb_synthesis_runs(fingerprint);
```

### 既有表：零改动
akb_assertions/evidence/semantic_units/compilation_runs/provenance 结构与语义不动
（provenance.activity 枚举值扩 'synthesize'——CHECK 若存在则随 migration 13 重建约束，
ADDITIVE 优先）。

### 约束/索引论证
- sets.fingerprint UNIQUE：Set 幂等锚（Q5/Q6 加减成员→新 fingerprint）；
- runs.fingerprint UNIQUE（NULL 允许）：合成幂等锚（锚语义同 V0.2 定案模式：锚=首个
  completed run 行，全部产物经 run 关联反查——不设第二锚）；
- status CHECK 含 capped（冲突爆炸人工复核语义）。

### backfill / rollback / 兼容
- 无 backfill（全新表，无历史数据语义变更）；
- rollback = DROP 两表 + 两索引（只被 V0.3 写入）；
- V0.1/V0.2 全部既有行为零影响（表为纯新增）。
