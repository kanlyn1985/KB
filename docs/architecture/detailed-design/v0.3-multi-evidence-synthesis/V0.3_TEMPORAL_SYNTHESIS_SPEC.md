# V0.3 Temporal Synthesis Spec

- Document ID: AKB-DD-V03-008 · Status: Design Baseline
- 继承 V0.2 五类时间分离（event/valid/observation/document_effective/ingestion）；
  **当前时钟永不参与语义时间**（T-02 锚定纪律延续）。

## 六态时间对齐

| 态 | 规则 |
|---|---|
| same | 各方锚定时间完全相等 |
| overlapping | valid_time 区间相交且非包含 |
| sequential | 区间不相交且 A.before(B)（可合成时序候选） |
| contradictory | 同实体同属性区间互斥（→TEMPORAL_CONFLICT） |
| missing | 成员无任何可解析时间（合法——不猜测） |
| unresolved | 存在未解析相对表达（parse_status=unresolved，标注待治理） |

## 规则

TS-01 same/overlapping 簇可合成（时间取交集语义并保留各方 raw）；
TS-02 sequential 簇可合成时序候选（predicates 附加 before/after 语义标注）；
TS-03 contradictory 不合成——转 ConflictDetector（TEMPORAL_CONFLICT）；
TS-04 missing 成员不阻断同簇其他成员合成（其时间字段置 NULL 并在 provenance 标注）；
TS-05 unresolved 成员候选的 temporal_scope 标 unresolved（治理复核提示）；
TS-06 全部时间语义字段锚定来源记录（document.effective_at/observation/ingestion）——
     审计可回放"这个时间从哪来"。
