# V0.3 Interface Behavior

- Document ID: AKB-DD-V03-015 · Status: Design Baseline
- 详细 input/output/pre/post/errors 见 ICD（docs/architecture/interfaces/V0.3_Multi_Evidence_Synthesis_ICD_V1.0.md）；
  本文件定行为要点与跨接口契约。

## 接口清单（7）

EvidenceSetManager / EvidenceAlignmentEngine / ConflictDetector / SourceWeightResolver /
SynthesisEngine（编排）/ SynthesisProvenanceStore / SynthesisValidator。

## 行为要点

1. SynthesisEngine.synthesize 为**唯一公开编排入口**（其他接口可独立单测但生产路径经编排）；
2. 幂等：synthesize 内部先算 Run 指纹→命中返回既有（零写）；Set 复用（同成员清单跨配置）；
3. 事务：per-run SAVEPOINT 原子（run+快照+candidates+provenance）；
4. 错误映射：全部 E-V03-* 按 ERROR_MODEL 隔离；
5. provider：只能经 SynthesisEngine 注入（对齐建议），ConflictDetector/Synthesis 裁决无 provider 面；
6. Validator 只读出报告（verification-only structure），不改状态；
7. Agent Runtime：无 synthesis 写接口（读 run 结果与 V0.1 同界）。

## 跨契约

- Set→Run：run.set_id 引用 Set；Run.fingerprint 含 Set 指纹；
- Run→Assertion：候选经 create_candidate 的 provenance 携带 run_id（synthesis 溯源主键）；
- 与 V0.2 compile 的关系：synthesize 要求成员已有 unit；缺 → 报错（调用方先跑 V0.2 compile）。
