# V0.3 Data Flow

- Document ID: AKB-DD-V03-003 · Status: Design Baseline

## 1. 对象级流

```text
[输入] evidence_ids[] (无序)
   ↓ EvidenceSetManager.create
[EvidenceSet] members sorted canonical ← fingerprint 锚（幂等）
   ↓ SynthesisEngine.synthesize
[Membership Validation] 全部成员存在且为治理 Evidence
   ↓
[SemanticUnit Retrieval] akb_semantic_units（V0.2 产物，只读；缺一 → E-V03-ALIGN-UNIT-MISSING）
   ↓
[Alignment] entity/relation/event/state/temporal 簇（derived，稳定编号）
   ↓
[Conflict Detection] 7 类（derived 快照；capped 语义）
   ↓
[Compatibility] 五级规则表分类
   ↓
[Source Weighting] weight_policy=v1（weight≠adjudication）
   ↓
[Candidate Synthesis] 按簇合成 → create_candidate（唯一边界）
   ↓                          CONFLICTING 簇候选带 conflict_ref
[SynthesisRun] canonical 行（含快照 JSON）+ Provenance(activity=synthesize)
   ↓
[V0.1 Governance]（不变）
```

## 2. 层间契约

| 阶段 | input | output | 失败行为 |
|---|---|---|---|
| Set 创建 | ids[], actor, cfg | EvidenceSetRecord | E-V03-SET-*（拒绝创建） |
| Membership | Set | 成员 Evidence 行 | 缺失 → E-V03-SET-MEMBER-NOT-FOUND |
| Retrieval | members | units[] | 缺 unit → E-V03-ALIGN-UNIT-MISSING（**不静默补编译**） |
| Alignment | units | AlignmentResult | 成员级失败隔离（标 INVALID 不阻断） |
| Conflicts | alignment | ConflictSet | capped → run=capped 转人工 |
| Compatibility | alignment | 五级分类 | 规则表全命中（无 default 放行） |
| Weights | members | SourceWeight[] | 策略未知 → uniform + warning |
| Synthesis | 簇+冲突+权重 | candidates | 簇级失败隔离；run 级失败回滚 |
| Provenance | 产物 | 五级链 | 缺失 → E-V03-SYNTH-PROVENANCE-MISSING（run failed） |

## 3. 不可变与生命周期

EvidenceSet（immutable——成员清单与指纹定后不变；内容变化→新 Set）；
SynthesisRun（immutable 审计体——状态推进 running→completed/failed/partial/capped）；
SemanticUnit（V0.2 immutable 语义）；ConflictSet 快照（随 run immutable）；
SynthesisCandidate（运行时对象，落库后即 KnowledgeAssertion(candidate)，进 V0.1 治理）。

## 4. 事务边界

一次 synthesize = 一个 SAVEPOINT 原子单元（Set 复用已有则不重复建）：
run 行 + 快照 JSON + candidates（经 create_candidate）+ provenance 全原子；
失败 → ROLLBACK TO + run 标 failed（append-only 审计保留）；
幂等命中 → 直接返回既有 run 产物（零写）。

## 5. 失败传播

成员级（单 unit 异常）→ 该成员标 INVALID 继续；簇级 → 该簇不产候选 + warning；
run 级（provenance/持久化/冲突爆炸 capped）→ run failed/capped 零半成品。
半成品永不成 authoritative（INV-002）。
