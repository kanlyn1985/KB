# V0.3 Source Weight Spec

- Document ID: AKB-DD-V03-009 · Status: Design Baseline
- 契约：**weight ≠ adjudication**——权重影响候选排序与置信度合成，绝不直接产生
  validated/asserted（INV-001/002/007 保持）。

## 维度（weight_policy=v1）

| 维度 | 来源 | 默认权重 |
|---|---|---|
| source authority | akb_sources.source_type 语义等级（governed>document>ingested） | 0.30 |
| source reliability | source 级历史质量元数据（无则中性 0.5） | 0.20 |
| recency | evidence.observed_at 距 document.effective_at 的逆衰减（锚定，非当前时钟） | 0.15 |
| document version | akb_documents.version 序（新版本高于旧版本） | 0.15 |
| evidence quality | extraction_method/confidence 元数据 | 0.10 |
| independent corroboration | 独立 source 计数（同源多证据不计独立） | 0.10 |

## 合成与使用

合成权重 = Σ(维度分×权重)（round 4）；用途仅两项：
①同一簇多候选的**排序**；②candidate confidence 合成（加权平均，各方原始 confidence 保留）。
缺策略 → uniform（全 1.0）+ warning；策略版本化进 configuration_hash。
