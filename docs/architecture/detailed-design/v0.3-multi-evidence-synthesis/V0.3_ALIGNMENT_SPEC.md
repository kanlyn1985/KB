# V0.3 Alignment Spec

- Document ID: AKB-DD-V03-006 · Status: Design Baseline

## 兼容性五级（规则表驱动，禁止模糊相似度单独裁决）

| 级别 | 判定规则（按序首中） |
|---|---|
| INVALID | 成员无 SemanticUnit / unit 结构非法 |
| INCOMPARABLE | 实体簇无交集（normalized_form 与 ontology_ref 均不重叠） |
| CONFLICTING | 同簇同谓词下 object 值域冲突（VALUE/TEMPORAL/ONTOLOGY 冲突存在） |
| PARTIALLY_COMPATIBLE | 部分簇对齐成功 + 部分未对齐/低置信 |
| COMPATIBLE | 全部关键簇对齐且无冲突 |

判定依据逐条记录（命中规则号+输入摘要）——审计可回放。

## Entity Alignment

- 键：normalized_form 精确匹配（L1）→ N-04..06 归一后匹配（L2）→ ontology_ref 同 ref（L3）；
- 别名匹配（V0.2 O-03 同源词表）为 L4（confidence 0.8）；
- 簇编号：按簇内最小 (evidence_id, candidate_id) 稳定编号（cl_0001…）。

## Relation Alignment

- 键：(subject_cluster, predicate_candidate, object_cluster)——谓词经 ontology 词表
  规范化（unknown 谓词独立簇 + warning）；
- 语义等价谓词映射表（has_parameter≡parameter_of 反向等规则）属 DomainPack 配置（版本化），
  内置最小映射集 derives from V0.2 R-01..06 谓词族。

## Event Alignment

- 键：(event_time 完全相等) AND (参与实体簇重叠 ≥1)；
- event_time 缺失成员不参与（不猜测——T-05 精神）。

## State Alignment

- 键：(subject_cluster, state 谓词族) + valid_time 不 contradictory；
- contradictory validity → 转 ConflictDetector（STATE_CONFLICT 候选）。
