# V0.3 Evidence Set Spec

- Document ID: AKB-DD-V03-005 · Status: Design Baseline

## 身份

```text
SynthesisSetFingerprint = SHA256(CanonicalJSON({
    "members": [evidence_id, ...],        // canonical：字典序排序
    "synthesis_version": "...",
    "configuration_hash": "..."
}))
```
六性质同 V0.2（字段名固定/排序规范化/无拼接/无 locale/无时钟/字节级比较）。

## 语义裁决（任务书 §9 七问）

- 顺序不敏感：[A,B] 与 [B,A] 同 fingerprint（canonical 排序消除顺序）——V03-CMP-002；
- 成员去重：重复 evidence_id → E-V03-SET-DUPLICATE-MEMBER（拒绝，不静默去重——显式失败优于隐藏语义）——V03-CMP-004；
- 基数：1..32（MAX_SET_SIZE 配置化，默认 32）；单成员 Set 合法（退化为单证据合成）；
- 内容变化：Evidence content 变 → V0.2 unit 新指纹 → synthesis 输入变 → 新 Set；
  旧 Set/Run 冻结（INV-005）；
- 加/减成员：新 fingerprint → 新 Set（旧 Set 完整可溯）；
- Evidence Set 是 identity+成员清单的幂等锚载体；多个 run 可复用同一 Set（不同 cfg → 不同 run 指纹）。

## 失败行为

空列表 → E-V03-SET-EMPTY；>32 → E-V03-SET-OVERSIZE；重复 → E-V03-SET-DUPLICATE-MEMBER；
任一 id 不存在 → E-V03-SET-MEMBER-NOT-FOUND（Set 整体不创建）。
