# V0.3 Pipeline（11 阶段规格）

- Document ID: AKB-DD-V03-004 · Status: Design Baseline
- 每阶段五要素：input/output/invariants/failure/provenance/determinism

| # | 阶段 | input→output | invariants | failure | determinism |
|---|---|---|---|---|---|
| 1 | Membership Validation | ids→治理 Evidence 行 | INV-001；去重 | 缺失→SET-MEMBER-NOT-FOUND | strict |
| 2 | Set Canonicalization | 行→sorted members+指纹 | [A,B]==[B,A] | 空/超限/重复→拒绝 | strict |
| 3 | Unit Retrieval | members→units[] | 只读 V0.2 产物 | 缺→UNIT-MISSING（不补编译） | strict |
| 4 | Entity Alignment | EntityCandidate→簇 | 候选级；不写 authoritative | 成员级隔离 | strict（normalized_form 精确/规范化匹配） |
| 5 | Relation Alignment | RelationCandidate→簇 | subj/obj 经实体簇解析 | 孤儿丢弃+warning | strict |
| 6 | Event/State Alignment | temporal+实体簇→事件/状态簇 | 缺时间不猜测 | 未对齐合法 | strict |
| 7 | Temporal Alignment | TemporalParse→六态分类 | 五类时间不合并；零时钟 | missing 合法 | strict |
| 8 | Conflict Detection | 簇+原始值→ConflictSet | 冲突不静默丢弃 | capped→人工 | strict（规则表） |
| 9 | Compatibility | 对齐+冲突→五级 | 规则表全命中 | 无 default 放行 | strict |
| 10 | Source Weighting | members→weights | weight≠adjudication | 未知策略→uniform+warning | strict |
| 11 | Candidate Synthesis | 簇+冲突+权重→candidates | **唯一边界 create_candidate**；恒 candidate；冲突带 conflict_ref | 簇级隔离/run 级回滚 | strict（排序（subject_ref,predicate_ref,object 值）） |

create_candidate 调用点：**仅阶段 11**——管线中不存在其他候选创建路径。
Provider（可选）只允许在阶段 4-6 输出对齐建议（过 schema validation），永不进入 8/11 裁决。
