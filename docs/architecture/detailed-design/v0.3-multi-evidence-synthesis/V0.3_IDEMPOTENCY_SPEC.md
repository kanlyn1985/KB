# V0.3 Idempotency Spec

- Document ID: AKB-DD-V03-013 · Status: Design Baseline

```text
same Evidence Set + same synthesis_version + same configuration
= same SynthesisFingerprint
```

## 持久化锚（显式，V0.2 锚语义模式延续）

```text
For V0.3:
- SynthesisFingerprint identifies one synthesis invocation.
- The SynthesisRun row with status=completed stores the fingerprint
  as the persistence anchor (ux_akb_synruns_fingerprint UNIQUE).
- All candidates created by that invocation are linked via
  provenance(run_id) / assertion.evidence_refs + run 反查。
- Failed/partial/capped runs have NULL fingerprint (multiple allowed).
- Fingerprint lookup MUST resolve the complete run (all candidates),
  never a partial view.
```

## 语义

- 幂等命中（同指纹重复 synthesize）→ 返回既有 run 全产物
  （E-V03-SYNTH-DUPLICATE 语义=幂等返回非错误）；
- 无第二次 create_candidate（候选由 run 反查）；
- 不同 cfg/版本 → 新指纹 → 新 run（旧产物不动，INV-005）；
- Set 复用：同成员清单跨配置复用同一 EvidenceSet 行（Set 指纹不含 run 配置中
  的 provider 参数——两段指纹设计：Set 指纹=成员+版本+核心 cfg；Run 指纹=Set+完整 cfg）。
