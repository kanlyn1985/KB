# V0.3 Multi-Evidence Semantic Synthesis Core — Detailed Design

- Document ID: AKB-DD-V03-001 · Version: V1.0 · Status: Design Baseline
- 基线：V0.2 RELEASE BASELINE（310f345）· V0.1 ACCEPTED · INV-001..010 全部保持

## 1. 上游考察（设计依据）

| 资产 | V0.3 复用方式 |
|---|---|
| V0.2 SemanticCompiler/单证据链 | 只读消费其 SemanticUnit 产物；缺 unit 报错不静默补编译 |
| AssertionStore.create_candidate | 唯一候选落库边界（V0.3 第二调用方，非第二路径） |
| Provenance(activity=compile 先例) | 扩展 activity=synthesize（机制复用） |
| canonical_json/fingerprint_spec=v1 | Set/Run 指纹同一约定（含锚语义模式） |
| SAVEPOINT per-run 事务先例 | synthesis per-run 原子 |
| SemanticCompilerProvider Protocol | provider 参与对齐建议（traceable），永不裁决 |

## 2. 数据流（冻结）

```text
Evidence A ─┐
Evidence B ─┼→ EvidenceSet（canonical，指纹锚）
Evidence C ─┘        ↓
        Membership Validation
                     ↓
        SemanticUnit Retrieval（V0.2 产物，只读）
                     ↓
        Entity/Relation/Event/State/Temporal Alignment（derived）
                     ↓
        Conflict Detection（7 类，derived 快照）
                     ↓
        Compatibility Classification（五级规则表）
                     ↓
        Source Weighting（weight≠adjudication）
                     ↓
        Candidate Synthesis ——→ create_candidate()（唯一边界）
                     ↓
        SynthesisRun（canonical）+ Provenance(activity=synthesize)
                     ↓
        V0.1 Governance（治理不变）
```

## 3. 不可破坏红线

1. INV-001..010 全部保持（V0.3 无任何削弱条款）；
2. create_candidate 是唯一候选落库路径（直写 SQL 被既有触发器拦截）；
3. 合成产物恒 status=candidate；CONFLICTING 簇候选必带 conflict_ref；
4. 成员 Evidence/SemanticUnit/历史 synthesis 结果 immutable（INV-005）；
5. 成员序 canonical（evidence_id 字典序）——[A,B]==[B,A] 同身份（V03-CMP-002）；
6. weight ≠ adjudication；
7. LLM/provider 只能建议对齐，永不裁决冲突/触碰治理；
8. Agent Runtime 零新增写路径；
9. V0.2 compile 行为零改变（synthesis 是新增入口）。

## 4. 数据模型变化（论证见 DATA_MODEL）

- 新表 akb_evidence_sets（Set 幂等锚载体）+ akb_synthesis_runs（run 聚合审计）；
- akb_assertions 不加列（synthesis 溯源经 provenance + evidence_refs 既有字段）；
- 对齐/冲突/权重随 run 留 JSON 快照（不建第二套中间表）。

## 5. 身份模型（任务书 §9 七问）

Q1 Evidence Set 身份 = SynthesisSetFingerprint = SHA256(CanonicalJSON({members_sorted,
synthesis_version, configuration_hash}))；
Q2 Set 对成员**顺序不敏感**（canonical 排序后哈希）；
Q3 [A,B]==[B,A]（同一 fingerprint——V03-CMP-002 行为级验证）；
Q4 Evidence 内容变化 → 该 evidence 的 content_hash 变化 → V0.2 编译产物新 fingerprint →
synthesis 输入变 → synthesis fingerprint 变（历史 Set/Run 不动——INV-005）；
Q5 加一条 → 成员清单变 → fingerprint 变 → 新 Set；
Q6 减一条 → 同上（新 Set；旧 Set 仍完整可溯）；
Q7 构造 = CanonicalJSON（字段名固定：members/synthesis_version/configuration_hash；
排序规范化；无隐式拼接；无 locale；无时钟；字节级比较——V0.2 同款六性质）。
