# V0.3 Provenance Spec

- Document ID: AKB-DD-V03-011 · Status: Design Baseline

五级链（INV-004 强化——多证据全溯源）：

```text
KnowledgeAssertion（evidence_refs=全部成员）
    ↓ provenance(activity=synthesize) + run_id
SynthesisRun（run_id，canonical）
    ↓ set_id
EvidenceSet（set_fingerprint，成员清单）
    ↓ members
Evidence[]（immutable）
    ↓ document_id
Document[]
```

查询面：describe_synthesis_run(run_id)（八问扩展：+Set 指纹/成员清单/冲突摘要）；
trace_candidate_synthesis(assertion_id)（断言→unit→run→set→members→documents 全链）。

规则：P-01 候选 evidence_refs 缺任一成员 = P0（E-V03-SYNTH-PROVENANCE-MISSING）；
P-02 provenance 写失败 → run failed 回滚（零半成品）；P-03 快照 JSON（alignment/conflicts/
weights）随 run 持久化——审计自包含（不依赖重算）；P-04 重复 trace 结果等价（确定性）。
