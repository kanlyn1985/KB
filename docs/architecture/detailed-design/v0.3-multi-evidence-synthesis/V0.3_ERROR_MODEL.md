# V0.3 Error Model

- Document ID: AKB-DD-V03-014 · Status: Design Baseline

## 错误码族

| 错误码 | 级 | 触发 | 隔离 |
|---|---|---|---|
| E-V03-SET-EMPTY | Set | 空成员清单 | 拒绝创建 |
| E-V03-SET-DUPLICATE-MEMBER | Set | 重复 evidence_id | 拒绝创建（不静默去重） |
| E-V03-SET-MEMBER-NOT-FOUND | Set | 成员不存在 | 拒绝创建 |
| E-V03-SET-OVERSIZE | Set | >MAX_SET_SIZE | 拒绝创建 |
| E-V03-ALIGN-UNIT-MISSING | 管线 | 成员缺 SemanticUnit | run failed（**不静默补编译**） |
| E-V03-ALIGN-FAILED | 成员 | 对齐异常 | 成员标 INVALID 继续 |
| E-V03-CONFLICT-EXPLOSION | run | >MAX_CONFLICTS | capped → 人工（不降级） |
| E-V03-WEIGHT-POLICY-UNKNOWN | 阶段 | 策略未知 | uniform 降级 + warning |
| E-V03-SYNTH-NONDETERMINISTIC | run | 重放校验不一致 | run failed |
| E-V03-SYNTH-DUPLICATE | run | 指纹命中 | **幂等返回**（非错误） |
| E-V03-SYNTH-PROVENANCE-MISSING | run | 链缺失 | run failed（P0 类） |
| E-V03-NOT-FOUND | 查询 | run/断言不存在 | 查询错误 |

## 失败不越界承诺

任何错误路径下：Evidence/authoritative Assertion 零修改；治理零绕过；
provenance 失败留痕；半成品永不成 authoritative（INV-002）。

## 三级隔离

成员级（INVALID 标记继续）→ 簇级（该簇零候选 + warning）→ run 级（SAVEPOINT 回滚 +
failed 审计保留）。
