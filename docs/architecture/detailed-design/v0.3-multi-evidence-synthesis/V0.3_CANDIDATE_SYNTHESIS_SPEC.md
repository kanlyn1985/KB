# V0.3 Candidate Synthesis Spec

- Document ID: AKB-DD-V03-010 · Status: Design Baseline

## 合成规则

S-01 对齐簇内 (subject_cluster, predicate, object_cluster) 完全一致 → 合成单一候选
     evidence_refs=全部成员 evidence_id（INV-004）；
S-02 数值兼容（同值不同精度）→ 取高精度表达 + 各方 raw 保留于 derivation.metadata；
S-03 CONFLICTING 簇：仍产候选（status=candidate）但**必带 conflict_ref**——治理复核后
     才能跃迁（V0.1 状态机）；
S-04 INCOMPARABLE 成员不参与合成（记录于 run.warnings）；
S-05 候选排序：按 (subject_ref, predicate_ref, object 值) 字典序（determinism）；
S-06 confidence = 加权平均（SourceWeight），round 4；各方原始 confidence 留 derivation；
S-07 assertion_type：全部成员 extracted/observed → synthesized_extracted 映射为 extracted
     （沿用 V0.2 四值域）；任何成员 hypothesized → hypothesized；
     **inferred 不由 V0.3 合成产生**（inferred 保留给 reasoner 通道——V0.4）。

## 唯一边界

create_candidate() 是全管线**唯一**候选落库调用点（阶段 11）；V0.3 不新增第二写入路径；
候选恒 status=candidate（INV-002/007/009）；AGENT/LLM 零特权。
