# V0.1 Interface Behavior

- Document ID: AKB-DD-V01-004 · Version: V1.0
- 对应 ICD：EvidenceStore(5.3) / AssertionValidator(5.4) / AssertionStore(5.5) 的 V0.1 具体化
- 通用约定：全部方法在单 SQLite 事务内；错误模型遵循 ICD §6；authorization 按 actor_id 前缀
  （human:/system:/llm:）静态判别；audit=transitions/provenance 行（随事务写入）。

## 1. EvidenceStore

### 1.1 create()
| 项 | 定义 |
|---|---|
| input | `{document_id, location{page?,section?,start,end}, content, evidence_type, observed_at?, extraction_method, confidence, metadata?}` |
| output | `EvidenceRecord`（含铸造的 evidence_id, content_hash） |
| precondition | document_id 存在；content 非空；confidence∈[0,1] |
| postcondition | evidence 行持久化；UNIQUE(document,content_hash,location) 冲突时返回既有记录 |
| errors | E-DOC-NOT-FOUND / E-DUPLICATE（幂等返回） / E-INVALID-LOCATION |
| idempotency | 天然幂等（内容寻址唯一约束） |
| transaction | 单事务 |
| authorization | actor ∈ human:/system:compiler |
| audit | created_at + extraction_method（evidence 行本身即审计单元） |

### 1.2 get()
`get(evidence_id) -> EvidenceRecord | E-NOT-FOUND`；纯读，无副作用。

### 1.3 trace()
| 项 | 定义 |
|---|---|
| input | `evidence_id` |
| output | `{evidence → document → source}` 全链（含版本与 hash） |
| precondition | evidence 存在 |
| errors | E-NOT-FOUND |
| idempotency | 纯读 |

## 2. AssertionStore

### 2.1 create_candidate()
| 项 | 定义 |
|---|---|
| input | `{subject_ref, predicate_ref, object{kind,value?,entity_ref?,datatype?,unit?}, assertion_type(extracted/observed/inferred/hypothesized), evidence_refs?, source_unit_refs?, temporal_scope?, ontology_scope, derivation?(inferred 必填), actor_id}` |
| output | `AssertionRecord`（status=candidate，铸造 assertion_id） |
| precondition | ontology_scope 受支持；type∈{extracted,observed,inferred,hypothesized}（**asserted 直接创建禁止**）；inferred ⇒ derivation 完整（rule_ref/parent_assertions/reasoner_id）；evidence_refs 中的 id 必须已存在 |
| postcondition | assertions 行（status=candidate）+ provenance 行；INV-007：llm: 前缀 actor 与 human 同待遇 |
| errors | E-INVALID-TYPE-FOR-CREATE / E-DERIVATION-MISSING（INV-002） / E-EVIDENCE-NOT-FOUND / E-ONTOLOGY-UNKNOWN |
| idempotency | 非 idempotent（每次创建新断言；重复内容检测由冲突查询层提供，G016） |
| transaction | 单事务（assertions + provenance） |
| authorization | actor ∈ human:/system:/llm:（全部允许——治理在迁移门） |
| audit | provenance(activity=create) |

### 2.2 get()
`get(assertion_id) -> AssertionRecord | E-NOT-FOUND`；含 derivation/canonical_json 反序列化。

### 2.3 list()
`list({status?, assertion_type?, subject_ref?, predicate_ref?, limit, offset}) -> [AssertionRecord]`；
强制分页（limit≤200）；排序 created_at DESC。冲突查询：`list_conflicts(subject_ref, predicate_ref)` →
同 S-P 多 object 的分组（G016 支撑）。

### 2.4 transition()
| 项 | 定义 |
|---|---|
| input | `{assertion_id, new_status, actor_id, reason, evidence_refs?(补证用)}` |
| output | `{assertion_id, previous_status, new_status, transition_id}` |
| precondition | 迁移合法（状态机 §3/§4 矩阵）；evidence 要求满足（INV-001）；inferred→asserted 直接拒绝 |
| postcondition | assertions.status 更新 + transitions 审计行 + provenance 行（同一事务） |
| errors | E-ILLEGAL-TRANSITION（附非法原因与迁移历史）/ E-INV-001-NO-EVIDENCE / E-EVIDENCE-NOT-FOUND / E-ACTOR-NOT-AUTHORIZED（§4 权限矩阵）/ E-ALREADY-IN-STATUS（幂等 no-op 返回成功语义） |
| idempotency | 已在目标状态 → 幂等 no-op；有中间迁移 → 拒绝 |
| transaction | **单事务四步原子序列**：validate permission → validate transition → validate evidence → INSERT transitions → controlled UPDATE status → INSERT provenance → COMMIT；任一步失败 ROLLBACK ALL（状态机 §8） |
| authorization | 见状态机 §4 权限矩阵（validated→asserted 仅 human） |
| audit | transition 行（actor/reason/policy_version/previous_status）+ provenance(activity=validate/promote/…) |

## 3. Provenance

### 3.1 trace()
| 项 | 定义 |
|---|---|
| input | `assertion_id` |
| output | `{assertion → evidence[] → document[] → source[]，含每跳 activity/actor/policy_version/occurred_at}` |
| precondition | assertion 存在 |
| errors | E-NOT-FOUND / E-CHAIN-BROKEN（上游引用缺失——视为 P0 数据完整性事件，同时触发 AG 巡检告警） |
| idempotency | 纯读 |
| 实现 | assertions.provenance_ref → provenance.inputs_json 闭包遍历，最多 4 跳（V0.1 链深固定） |

## 4. AssertionValidator

### 4.1 validate()
| 项 | 定义 |
|---|---|
| input | `{assertion_id, actor_id=system:validator}` |
| output | `{accepted: bool, violations: [code]}`；accepted 时内部执行 transition(candidate→validated) |
| precondition | status=candidate；evidence_refs 非空且每条 evidence 可解析（content hash 复核） |
| postcondition | 通过：status=validated + 审计；失败：status 保持 candidate + violations 记录于 provenance.metadata |
| errors | E-INV-001-NO-EVIDENCE / E-EVIDENCE-BROKEN（hash 不符）/ E-WRONG-STATUS |
| idempotency | 对 validated 断言重复 validate → no-op |
| authorization | 仅 system:validator（服务内部调用） |

### 4.2 can_transition()
`can_transition(assertion_record, new_status, actor_id) -> {allowed, violations[]}` ——
纯函数式预检（状态机矩阵+权限矩阵+INV 规则），供 UI/上层预判，无副作用。

## 5. Graph 投影接口（V0.1 最小面）

### 5.1 project_edge()
`project_edge({assertion_id, source_ref, target_ref, predicate_ref, actor_id=system:projector})` ——
写 graph_edges(assertion_ref=...)；**precondition: assertion.status ∈ {validated,asserted}**
（candidate/hypothesized/rejected/deprecated 断言不得经本接口投影——本接口即 PATH B Runtime Projection；
candidate 的 legacy 回填走 PATH A 迁移脚本，与本 API 无关，见 §6.1）；投影失败（约束/锁）→
事务回滚且 **断言行零变更**（INV-006，V0.1-GRAPH-002）。

### 5.2 refresh_projection()
按 policy 重建某断言的投影（deprecated/rejected → tombstone 标记）。

## 6. Projection Paths（PATH A vs PATH B）

### 6.1 正式定义

| | PATH A — Migration Backfill | PATH B — Runtime Projection |
|---|---|---|
| 用途 | legacy graph_edges 兼容性链接 | 正常知识投影 |
| 入口 | 迁移脚本（system:migrator，一次性） | project_edge() API（system:projector） |
| 允许的断言状态 | candidate（历史事实登记） | **仅 validated / asserted** |
| 性质 | 不是 Canonical Projection | Canonical Projection（ADR-002） |
| 审计 activity | migrate | project |
| 验证 | V0.1-GRAPH-001B | V0.1-GRAPH-001A |

**禁止**把 PATH A 解读为"candidate 可进入正常投影"；两路径仅共享 assertion_ref 列。

### 6.2 Semantica Adapter Boundary（ADR-006 落实）

```text
Semantica 库（Pipeline/ER/Graph/Temporal/Reasoning/Provenance 机制）
        ↓ 仅经以下边界
[akb_semantica_adapter]（未来包，V0.1 不建）
        ↓ 实现以下 AKB 接口
EvidenceStore / AssertionStore / AssertionValidator（本文件契约）
```

- V0.1 约束：Evidence/Assertion Core **零 Semantica import**（后续加 import-lint 时将
  `semantica` 列入禁用清单——AG-005）；
- 未来说明：Semantica ER 产出 → 经 create_candidate 进入治理链（不得直接落 assertions 表）；
  Semantica Graph → 只能作为 SemanticGraph 投影的后端（ADR-002），其图对象不进 Canonical。
