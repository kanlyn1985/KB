## 1. Scope（严格边界）

### 1.1 In Scope（本版本实现）

| 组件 | 对应 Data Model | 对应 Gap |
|---|---|---|
| Source 注册与读取 | DM-001 | — |
| Document 版本管理 | DM-002 | — |
| Evidence 存储与溯源 | DM-003 | — |
| SemanticUnit（中间 IR，只做数据结构） | DM-004 | — |
| KnowledgeAssertion（Canonical Knowledge Unit） | DM-005 | AG-002 |
| AssertionValidator（状态迁移治理） | DM-005 §9.4 | AG-002 |
| AssertionStore（持久化与查询） | DM-005 | AG-002 |
| Assertion Transition Audit | DM-005 §9.4 | AG-004 |
| Provenance 链（trace） | DM-003/005 | — |
| graph_edges.assertion_ref 迁移 | DM-007 | AG-001 |
| ReasoningTrace / Derived Assertion **数据结构**（不含执行器） | DM-012 | AG-003（部分） |

### 1.2 Out of Scope（禁止在本版本扩展）

复杂 Planning / 复杂 Decision / 复杂 Action / 复杂 Memory / Causal Reasoning / 自主 Agent Loop
——全部属后续版本（V0.2+，依 DM-013..018 实现计划）。ReasoningEngine 执行器不在 V0.1
（Golden R001..R006 在 V0.1 只验证 schema/derivation 结构/parent 引用，见 §8）。

### 1.3 依赖边界

- **V0.1 不依赖 Semantica**（ADR-006）：Evidence/Assertion Core 纯自研，Semantica 留作未来
  Semantic Runtime Provider（见 v0.1_interface_behavior.md §6 Adapter Boundary）；
- **不引入新数据库**：SQLite（现有 node-index 同库不同表，ADDITIVE FIRST）；
- Agent 平面只读（ADR-008/INV-008）：V0.1 无 Agent 写路径。

## 2. 架构位置

```text
[现有] node-index.sqlite3                    [新增 V0.1]
  facts / cards / graph_edges / evidence  →   sources / documents / evidence /
  （保持不动，作为编译输入）                  semantic_units / assertions /
                                              assertion_transitions / provenance
                                                        ↓ 投影
                                              graph_edges.assertion_ref（回填）
```

## 3. 核心治理链（冻结）

```text
Source → Document → Evidence → SemanticUnit → Assertion → (Projection: Graph/Vector/Lexical)
                                      ↓
                            AssertionValidator（状态机治理，INV-001/002）
                                      ↓
                            assertion_transitions（审计，INV-005 部分）
```

## 5. 不变量落实对照

| Invariant | V0.1 落实机制 | 验证 |
|---|---|---|
| INV-001 Evidence Gate | AssertionValidator 拒绝无证据 validated/asserted | V0.1-AST-002 |
| INV-002 Derived Isolation | inferred 必带 derivation 块 + status=candidate 锁定 | V0.1-AST-004 |
| INV-003 Graph Traceability | graph_edges.assertion_ref + 回填 | V0.1-GRAPH-001 |
| INV-004 Evidence Traceability | provenance.trace(assertion_id) 全链 | V0.1-PROV-001 |
| INV-005 History Integrity | assertions 行不可 UPDATE（append-only + transitions 审计） | V0.1-AST-005 |
| INV-006 Index Independence | 投影失败不改 Canonical（事务边界） | V0.1-GRAPH-002 |
| INV-007 LLM Governance Gate | LLM 产出与人工产出同走 create_candidate→validate 链 | V0.1-AST-001（同一入口） |
| INV-008 Agent Write Boundary | V0.1 无 Agent 写 API；store 接口按 principal 校验（预留） | V0.1-AST-005 |
| INV-009 Memory Promotion Gate | Memory 不在 V0.1 范围（表不建） | — |
| INV-010 Action Policy Gate | 无 Action 对象（V0.2+） | — |
