## 1. Evidence

### V0.1-EVD-001 Evidence identity
- Given: 同一 document、同 content、同 location 两次 create()
- When: 第二次 create
- Expected: 返回同一 evidence_id（幂等）；content_hash 确定性
- INV: INV-004 · RTM: SYS-003/T-EVD-001

### V0.1-EVD-002 Evidence lineage
- Given: evidence 及其 document/source
- When: EvidenceStore.trace()
- Expected: 返回完整 evidence→document→source 链，字段齐全
- INV: INV-004 · RTM: SYS-011/T-EVD-002

## 2. Assertions

### V0.1-AST-001 Candidate assertion creation
- Given: 合法输入（extracted/observed/inferred/hypothesized 各一）
- When: AssertionStore.create_candidate()
- Expected: status=candidate；assertion_id 铸造；inferred 必带 derivation 否则 E-DERIVATION-MISSING；
  llm: actor 与 human: actor 产物结构完全一致（INV-007）
- RTM: SYS-004/T-AST-001

### V0.1-AST-002 No evidence → no validated/asserted
- Given: evidence_refs=[] 的 candidate
- When: validator.validate() / transition(validated|asserted)
- Expected: 拒绝（E-INV-001-NO-EVIDENCE）；status 仍 candidate；DB CHECK 兜底（绕过 API 直写 SQL 亦失败）
- INV: INV-001 · RTM: SYS-005/T-AST-002

### V0.1-AST-003 Valid evidence → validated
- Given: candidate 且 evidence_refs≥1（hash 复核通过）
- When: validator.validate()
- Expected: status=validated + transitions 审计行（actor=system:validator）
- INV: INV-001 · RTM: SYS-005/T-AST-003

### V0.1-AST-004 Derived assertion requires derivation
- Given: assertion_type=inferred
- When: create_candidate(无 derivation) / SQL 直写无 derivation_json
- Expected: API 层 E-DERIVATION-MISSING；DB 层 CHECK 失败
- INV: INV-002 · RTM: SYS-010/T-AST-004

### V0.1-AST-005 Illegal transition rejected
- Given: 状态机 §3 非法组合表（直创 asserted / inferred→asserted / validated→candidate / rejected→any）
- When: transition()
- Expected: E-ILLEGAL-TRANSITION，返回迁移历史；数据零变更
- INV: INV-002/005/008 · RTM: SYS-006/T-AST-005

### V0.1-AST-006 Transition audit generated
- Given: 任意合法迁移
- When: 迁移完成后查 assertion_transitions
- Expected: 恰一行，含 previous_status/new_status/actor_id/reason/policy_version；append-only 触发器拒绝 UPDATE/DELETE
- INV: INV-005 · RTM: SYS-006/T-AST-006
