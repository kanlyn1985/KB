# V0.1 Database Design

- Document ID: AKB-DD-V01-002 · Version: V1.0 · Status: Ready for Implementation
- 原则：ADDITIVE FIRST（AGENTS.md 仓库规则）；Canonical 语义不因 SQLite 存储选择改变（ADR-001）；
  结构化列承载查询/约束语义，canonical JSON 列承载完整对象保真（双向可重建 DM-005 对象）。

## 通用约定

- 所有表：`created_at TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%SZ','now'))`（UTC ISO-8601）；
- 主键 TEXT（AKB 铸造，禁止 provider id 作主键——ADR-009）；
- ID 前缀：`src_` / `doc_` / `evd_` / `su_` / `ast_` / `astt_` / `prov_`；
- 迁移框架：`agent_kb.storage.migrations.SchemaMigrator`（现有设施）；
- 每表 audit 字段见各表"审计"小节；append-only 表用触发器强制（见 §7 triggers）。

## 1. sources

```sql
CREATE TABLE IF NOT EXISTS sources (
  source_id       TEXT PRIMARY KEY,             -- 'src_xxx' AKB 铸造
  source_type     TEXT NOT NULL CHECK (source_type IN
                    ('document','database','api','sensor','human','agent','system')),
  name            TEXT NOT NULL CHECK (length(name) > 0),
  authority_score REAL CHECK (authority_score BETWEEN 0 AND 1),
  owner           TEXT,
  access_policy_ref TEXT,
  metadata_json   TEXT NOT NULL DEFAULT '{}',   -- canonical JSON（保真）
  created_at      TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%SZ','now')),
  updated_at      TEXT
);
CREATE UNIQUE INDEX IF NOT EXISTS ux_sources_name_type ON sources(source_type, name);
```

- purpose: 信息来源注册（DM-001）；Source 不是 fact（ADR-001）。
- immutability: source_id/source_type 不可变；name/authority_score 可更新（记 updated_at）。
- 迁移注：首条种子 Source=`src_kb1_corpus`（现有 KB1 语料库整体作为初始 Source）。

## 2. documents

```sql
CREATE TABLE IF NOT EXISTS documents (
  document_id   TEXT PRIMARY KEY,               -- 'doc_xxx'
  source_id     TEXT NOT NULL REFERENCES sources(source_id),
  version       TEXT NOT NULL,                  -- '1.0'
  content_hash  TEXT NOT NULL,                  -- 'sha256:<hex>'（不可变 artifact 必填）
  mime_type     TEXT,
  title         TEXT,
  effective_at  TEXT,
  ingested_at   TEXT NOT NULL,
  metadata_json TEXT NOT NULL DEFAULT '{}',
  created_at    TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%SZ','now')),
  UNIQUE (source_id, content_hash)              -- 同源同内容=同一文档版本
);
CREATE INDEX IF NOT EXISTS ix_documents_source ON documents(source_id);
```

- immutability: **全表 append-only**（内容变更=新 version 行，DM-002）。
- 与现有 `doc:node:<node>` 引用兼容：迁移期建映射行（V0.1_MIGRATION_PLAN §3）。

## 3. evidence

```sql
CREATE TABLE IF NOT EXISTS evidence (
  evidence_id      TEXT PRIMARY KEY,            -- 'evd_xxx'（新体系）
  document_id      TEXT NOT NULL REFERENCES documents(document_id),
  location_page    INTEGER,
  location_section TEXT,
  location_start   INTEGER,
  location_end     INTEGER,
  content          TEXT NOT NULL,               -- 原文（非摘要）
  evidence_type    TEXT NOT NULL DEFAULT 'text'
                     CHECK (evidence_type IN ('text','table','image','observation','system_record')),
  observed_at      TEXT,
  extraction_method TEXT NOT NULL,
  confidence       REAL CHECK (confidence BETWEEN 0 AND 1),
  metadata_json    TEXT NOT NULL DEFAULT '{}',
  content_hash     TEXT NOT NULL,               -- evidence identity 确定性（DM-003）
  created_at       TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%SZ','now')),
  UNIQUE (document_id, content_hash, location_start, location_end)
);
CREATE INDEX IF NOT EXISTS ix_evidence_document ON evidence(document_id);
```

- purpose: 最小可审计信息单元（DM-003）；Evidence identity = hash+doc+位置（稳定可重导）。
- immutability: **append-only**（Evidence 不可改——INV-005 的物质基础）。
- 兼容：现有 `evd:node:<node>:<n>` 引用体系保留不动；V0.1 新证据用 `evd_` 前缀；
  Golden 的 `evd:gold:*` 属 golden 本地资产不入生产表。

## 4. semantic_units

```sql
CREATE TABLE IF NOT EXISTS semantic_units (
  unit_id        TEXT PRIMARY KEY,              -- 'su_xxx'
  evidence_id    TEXT NOT NULL REFERENCES evidence(evidence_id),
  unit_type      TEXT NOT NULL,                 -- 归一化段落/抽取候选/表格行…
  normalized_text TEXT NOT NULL,
  entity_candidates_json TEXT NOT NULL DEFAULT '[]',
  relation_candidates_json TEXT NOT NULL DEFAULT '[]',
  temporal_parse_json    TEXT,
  ontology_mapping_json  TEXT,
  extraction_method TEXT NOT NULL,
  extraction_version TEXT NOT NULL,
  created_at     TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%SZ','now'))
);
CREATE INDEX IF NOT EXISTS ix_su_evidence ON semantic_units(evidence_id);
```

- purpose: Evidence→Assertion 中间 IR（DM-004）；**永不自动视为 authoritative**。
- 与现有 facts 表关系：facts 是 KB1 编译产物（历史输入），V0.1 迁移时经映射转 candidate 断言（§B10 映射表），facts 表本体不动。

## 5. assertions

```sql
CREATE TABLE IF NOT EXISTS assertions (
  assertion_id   TEXT PRIMARY KEY,              -- 'ast_xxx'
  subject_ref    TEXT NOT NULL,                 -- 'entity:xxx' / 'doc:xxx' / 'source_id:xxx'
  predicate_ref  TEXT NOT NULL,                 -- 'relation:xxx'（受 ontology_scope 约束）
  object_kind    TEXT NOT NULL CHECK (object_kind IN ('literal','entity_ref')),
  object_value   TEXT,                          -- literal 时必填
  object_datatype TEXT,
  object_unit    TEXT,
  object_entity_ref TEXT,                       -- entity_ref 时必填
  assertion_type TEXT NOT NULL CHECK (assertion_type IN
                   ('extracted','observed','asserted','inferred','hypothesized')),
  status         TEXT NOT NULL CHECK (status IN
                   ('candidate','validated','asserted','disputed','rejected','deprecated')),
  confidence     REAL CHECK (confidence BETWEEN 0 AND 1),
  evidence_refs_json TEXT NOT NULL DEFAULT '[]',  -- ["evd_xxx", ...]（顺序保留）
  source_unit_refs_json TEXT NOT NULL DEFAULT '[]',
  provenance_ref TEXT REFERENCES provenance(provenance_id),
  temporal_scope_json TEXT,                     -- {valid_from,valid_until,observed_at}
  ontology_scope TEXT NOT NULL,                 -- 'ontology:obc_dcdc:0.6'
  derivation_json TEXT,                         -- 非空当 assertion_type='inferred'（CHECK 强制）
  canonical_json TEXT NOT NULL,                 -- 完整 DM-005 对象序列化（保真层）
  created_at     TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%SZ','now')),
  updated_at     TEXT,
  CHECK (object_kind = 'literal'  OR object_entity_ref IS NOT NULL),
  CHECK (object_kind != 'literal' OR object_value IS NOT NULL),
  CHECK (status NOT IN ('validated','asserted','disputed') OR
         json_array_length(evidence_refs_json) >= 1),          -- INV-001 数据层强制
  CHECK (assertion_type != 'inferred' OR derivation_json IS NOT NULL),  -- INV-002
  CHECK (assertion_type = 'inferred' OR status != 'candidate' OR derivation_json IS NULL)
);
CREATE INDEX IF NOT EXISTS ix_assertions_subject ON assertions(subject_ref);
CREATE INDEX IF NOT EXISTS ix_assertions_status  ON assertions(status);
CREATE INDEX IF NOT EXISTS ix_assertions_spo     ON assertions(subject_ref, predicate_ref, object_value);
```

- purpose: **Canonical Knowledge Unit**（ADR-001 冻结）。
- **append-only 语义**：`subject_ref/predicate_ref/object_*/assertion_type` 不可 UPDATE；
  状态变更不走 UPDATE assertions.status，而走 §6 transitions 触发的**受控单字段更新**
  （触发器校验：仅 status/updated_at/provenance_ref 可变，且必须在 transitions 有对应行——V0.1-AST-005）；
- 冲突检测（Golden G016）：同 (subject_ref,predicate_ref) 多行即潜在冲突，查询层暴露（不合并）。

## 6. assertion_transitions

```sql
CREATE TABLE IF NOT EXISTS assertion_transitions (
  transition_id   TEXT PRIMARY KEY,             -- 'astt_xxx'
  assertion_id    TEXT NOT NULL REFERENCES assertions(assertion_id),
  previous_status TEXT NOT NULL,
  new_status      TEXT NOT NULL CHECK (new_status IN
                    ('candidate','validated','asserted','disputed','rejected','deprecated')),
  actor_id        TEXT NOT NULL,                -- 'human:<id>' / 'system:<component>'
  reason          TEXT NOT NULL CHECK (length(reason) > 0),
  policy_version  TEXT NOT NULL,                -- 'policy:v0.1'
  provenance_ref  TEXT REFERENCES provenance(provenance_id),
  created_at      TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%SZ','now'))
);
CREATE INDEX IF NOT EXISTS ix_astt_assertion ON assertion_transitions(assertion_id);
```

- 审计完整性：**append-only**；每次合法迁移恰一行；幂等性由"同 (assertion_id,new_status) 且
  无中间迁移则拒绝重复迁移"保证（Validator 层）。
- 谁可迁移：actor=human:<id>（validated→asserted 等治理跃迁）；actor=system:validator
  （candidate→validated 自动门，evidence 校验通过时）；actor=system:reasoner（仅产出 candidate，
  见状态机文档非法迁移表）。

## 7. provenance

```sql
CREATE TABLE IF NOT EXISTS provenance (
  provenance_id  TEXT PRIMARY KEY,              -- 'prov_xxx'
  actor_id       TEXT NOT NULL,
  actor_kind     TEXT NOT NULL CHECK (actor_kind IN ('human','system','agent','llm')),
  activity       TEXT NOT NULL,                 -- 'import','extract','validate','promote','reason','project'
  policy_version TEXT NOT NULL,
  occurred_at    TEXT NOT NULL,
  inputs_json    TEXT NOT NULL DEFAULT '[]',    -- 引用的上游 id 列表
  metadata_json  TEXT NOT NULL DEFAULT '{}',
  created_at     TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%SZ','now'))
);
```

- trace(assertion_id) 实现：assertions.provenance_ref → provenance.inputs_json →
  evidence_ids → documents → sources（闭包遍历，见 interface_behavior §3）。

## 8. graph_edges 迁移（ADDITIVE）

```sql
ALTER TABLE graph_edges ADD COLUMN assertion_ref TEXT REFERENCES assertions(assertion_id);
CREATE INDEX IF NOT EXISTS ix_graph_edges_ast ON graph_edges(assertion_ref);
```

- 回填策略/失效投影处理/幂等：见 V0.1_MIGRATION_PLAN.md §2-§4。
- 约束落地节奏：V0.1 列可空（存量回填）；V0.2 起 NOT NULL（全部边经断言投影）。

## 9. Append-only 触发器（示例，evidence；assertions/transitions 同型）

```sql
CREATE TRIGGER IF NOT EXISTS trg_evidence_no_update
BEFORE UPDATE ON evidence
BEGIN
  SELECT RAISE(ABORT, 'INV-005: evidence is append-only');
END;
CREATE TRIGGER IF NOT EXISTS trg_evidence_no_delete
BEFORE DELETE ON evidence
BEGIN
  SELECT RAISE(ABORT, 'INV-005: evidence is append-only');
END;
```

## 10. 与现有 schema 的隔离

- 全部新表建在现有 DB（同文件，附加 schema），零改动既有表结构（graph_edges 仅 ADD COLUMN）；
- 现有 evidence 语义：KB1 `evidence` 表已存在（evd:node:*）——**V0.1 新表命名采用 `akb_evidence`？**
  **否**：SQLite 无跨库命名空间，为避免冲突，V0.1 表名统一加前缀——最终定名：
  `akb_sources / akb_documents / akb_evidence / akb_semantic_units / akb_assertions /
   akb_assertion_transitions / akb_provenance`（本文档以上 §1-§7 的裸表名均按此前缀落库），
  graph_edges 既有表仅加列。此决定记录于 MIGRATION_PLAN §1。
