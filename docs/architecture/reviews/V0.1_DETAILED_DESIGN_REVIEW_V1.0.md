## Remaining Risks

1. SQLite 触发器 9.2a 的 `IS NOT` 值比对语义在实现期需按版本实测（文档已注明"微调但守卫语义不变"）；
2. PATH A 生成的 467 条 candidate 断言的治理节奏未定（谁在何时 validate→promote）——属运营决策，不影响设计一致性；
3. akb_evidence 完整搬运延至 V0.2——legacy resolver 生命周期与 V0.2 绑定，需在 V0.2 设计中显式退役。
