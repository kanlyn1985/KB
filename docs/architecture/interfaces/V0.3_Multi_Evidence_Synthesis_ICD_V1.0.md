# V0.3 Multi-Evidence Synthesis — Interface Control Document V1.0

- Document ID: AKB-ICD-V03-001 · Status: Design Baseline
- 位置：`agent_kb/evidence_core/synthesis/`（V0.2 compilation 子包同级——复用 storage/治理设施，零第二套基建）
- 通用约定：全部接口 deterministic（builtin）/traceable（provider）；错误码族 E-V03-*；
  事务边界 per-run SAVEPOINT；授权 actor_id 前缀同 V0.1；provenance(activity=synthesize)。

## 1. EvidenceSetManager

- input：`create(evidence_ids: list[str], actor_id: str, config: dict) -> EvidenceSetRecord`
- output：EvidenceSetRecord（set_id/成员清单/fingerprint/created_at）
- preconditions：全部 evidence_id 存在于 akb_evidence；成员去重后 1..32；列表非空
- postconditions：Set 行持久化；fingerprint 计算；provenance(activity=synthesize,inputs=ids)
- errors：E-V03-SET-{EMPTY,DUPLICATE-MEMBER,MEMBER-NOT-FOUND,OVERSIZE}
- transaction：单 INSERT 原子
- determinism：set_id 由 fingerprint 派生；成员清单 canonical（evidence_id 字典序）
- authorization：actor 任意前缀（创建 Set 非治理动作）
- provenance：Set 创建留痕

## 2. EvidenceAlignmentEngine

- input：`align(units: list[SemanticUnitRecord], config) -> AlignmentResult`
- output：AlignmentResult{entity_clusters, relation_clusters, event_clusters, state_clusters,
  temporal_alignment, compatibility}
- preconditions：全部 unit 来自 Set 成员（unit.evidence_id ∈ members）；unit 为 V0.2 编译产物
- postconditions：五级兼容性分类 + 判定依据记录；排序稳定
- errors：E-V03-ALIGN-{UNIT-MISSING,FAILED}（成员级隔离）
- transaction：只读（对齐纯函数）
- determinism：strict（规则表驱动；聚类 ID 按首成员序稳定编号）
- authorization：无治理面
- provenance：对齐快照随 run 留 JSON

## 3. ConflictDetector

- input：`detect(alignment: AlignmentResult, units) -> ConflictSet`
- output：ConflictSet{conflicts[7 类], unresolved_count, capped: bool}
- preconditions：对齐完成
- postconditions：每冲突含 source_evidence_ids/unit_ids/fields/method/confidence/provenance；
  冲突数 >128 → capped=True（run 转人工，不静默降级）
- errors：E-V03-CONFLICT-EXPLOSION（capped 时 run 级状态）
- transaction：只读
- determinism：strict（分类规则表驱动）
- authorization：无
- provenance：随 run

## 4. SourceWeightResolver

- input：`resolve(members: list[EvidenceRecord], policy_version: str) -> list[SourceWeight]`
- output：逐成员 SourceWeight（authority/reliability/recency/version/quality/corroboration
  维度分解 + 合成权重，weight_policy=v1）
- preconditions：成员 Evidence 可读；policy 版本存在（缺省 uniform）
- postconditions：权重只影响 candidate 排序/置信度（weight≠adjudication 契约）
- errors：E-V03-WEIGHT-POLICY-UNKNOWN（→ uniform 降级 + warning，不失败）
- transaction：只读
- determinism：strict
- authorization：无
- provenance：随 run

## 5. SynthesisEngine（编排器）

- input：`synthesize(evidence_ids: list[str], actor_id: str, config: dict) -> SynthesisResult`
- output：SynthesisResult{run, set, alignment, conflicts, weights, candidates[], warnings,
  fingerprint, idempotent_hit}
- preconditions：Set 可创建/已存在；全部成员有 SemanticUnit（无则先跑 V0.2 compile——
  复用现有 SemanticCompiler，缺一报错不静默补编译）
- postconditions：候选恒 status=candidate；幂等命中返回既有 run 全产物；
  CONFLICTING 簇候选携带 conflict_ref
- errors：E-V03-SYNTH-{NONDETERMINISTIC,DUPLICATE,PROVENANCE-MISSING,CONFLICT-EXPLOSION}
- transaction：per-run SAVEPOINT（run/set/candidates/provenance 原子；失败回滚留 failed 审计）
- determinism：成员序 canonical → 全管线 strict（builtin）；provider 参与则 traceable
- authorization：actor 可为 human:/system:；llm: 仅可作 provider 内部角色，不可发起治理
- provenance：五级链（Candidate→Run→Set→Evidence[]→Document[]）

## 6. SynthesisProvenanceStore

- input：`describe_synthesis_run(run_id) / trace_candidate_synthesis(assertion_id)`
- output：run 全字段 / {assertion, unit_refs, run, set, members[], documents[]}
- preconditions：run/assertion 存在
- postconditions：确定性重复查询等价
- errors：E-V03-NOT-FOUND
- transaction：只读
- determinism：strict
- authorization：只读（与 V0.1 查询面同界）

## 7. SynthesisValidator

- input：`validate(result: SynthesisResult, store: AssertionStore) -> ValidationReport`
- output：逐候选 {assertion_id, status=candidate, evidence_refs 完整性, conflict_ref 存在性,
  derivation 完整性（inferred 时）}
- preconditions：synthesis 完成
- postconditions：报告只读；不改变任何状态；报告作为治理复核输入
- errors：报告级 findings（不抛断言错误）
- transaction：只读
- determinism：strict
- authorization：无
- provenance：报告不持久化（verification-only structure）

## 8. Provider 边界（V0.3 扩展）

V0.2 SemanticCompilerProvider Protocol 延续语义：V0.3 允许 provider 参与**对齐建议**
（alignment hints），输出必须过 schema validation；provider 永不接触
ConflictDetector 裁决/治理/create_candidate。LLM 输出标记 traceable（provider metadata 全记录）。
