## Architecture Summary（四 runtime 模块）

```text
Hypothesis（open → supported/refuted/withdrawn——独立生命周期）
    ↓ 绑定（E-V08-HYPOTHESIS-NOT-FOUND fail-closed）
VerificationTask（created → running → completed/failed/cancelled）
    ↓ completed 门控（E-V08-TASK-NOT-COMPLETED）
Verdict（supported/refuted/inconclusive 白名单——驱动受控迁移）
    ↓ EvolutionView（只读聚合：timeline seq 序 + provenance_refs）
知识演化审计闭环（零 assertion 直通/零图写入/零 promotion 直通）
```

- **Hypothesis Runtime**：create（deterministic hyp_id）/get/withdraw/
  transition_status 受控原语——provenance-only 存储（seq 锚重放）；
- **VerificationTask Runtime**：注册/绑定校验/五状态生命周期——零 hypothesis
  状态修改；
- **Verdict Runtime**：六道 fail-closed 门（hypothesis/task/completed/绑定/
  evidence 实表/结果白名单）+ 迁移驱动（open→supported/refuted；inconclusive
  记史）；
- **EvolutionView Runtime**：只读聚合（timeline/tasks/verdicts/refs）+
  evw fingerprint——零写入实测。

## Provenance Model

graph:hypothesis-create / graph:hypothesis-status / graph:hypothesis-withdraw /
graph:verification-task-create|start|complete|failed|cancel /
graph:hypothesis-verdict——全部进入 akb_provenance（metadata 携带 seq 单调锚 +
各 ref/快照）；可追溯、可重放、零第二套审计系统。

## Determinism Guarantees（FINAL 独立复算）

hypothesis_id / verification_task_id / verdict_id / evolution_view fingerprint
——四项同输入同输出、差异输入异输出全部独立复算 PASS；canonical JSON 派生；
零 timestamp/零 random/零 runtime ordering 依赖。

## Governance Boundary

- hypothesis 不进入 akb_assertions/kg_*（HY/VT/VD/EV 四套件泄漏测试实测）；
- inferred/validated/asserted 对 hypothesis 禁入（E-V08-INVALID-TRANSITION）；
- supported 零直通 assertion/validated/kg projection（零 promotion 路径）；
- verdict 结果白名单 validated/asserted/inferred 禁入；
- EvolutionView 只读（零写入实测）；
- governance human-only 边界延续（verdict actor human 域，V0.4 既有晋升通道
  不变）。

## Known Limitations（P2，accepted）

1. **P2-01** provenance-only 查询面为全表扫描（get/list view）——批量索引/
   分页属 V0.9 runtime optimization 候选；
2. **P2-02** verdict evidence 校验深度 = 存在性（设计 P1 定标项默认档）——
   五级链回溯叠加可后续叠加；
3. **P2-03** evolution analytics（按域/按 policy 聚合视图）为后续扩展；
4. **P2-04** registry 内存态（延续 V0.7 P2-01）。

## P1 开放项（不阻断 V0.8 freeze）

- **P1-01** provenance-only query scalability——大数据量下 get/list view 全表
  扫描；缓解路径：方案 b（migration 16）需显式批准，或 V0.9 索引优化；
- **P1-02** evidence validation depth = 存在性——五级链回溯可叠加（Verdict
  阶段既定默认档）。

## Out of Scope（V0.9+ / 永久）

- V0.9+：multi-step causal reasoning（需因果 ontology 冻结）、runtime
  optimization（registry 持久化/批量注入/查询分页/索引）、hypothesis 自动
  实验设计、evolution analytics；
- 永久禁止：LLM as source of truth / vector DB / embedding / distributed /
  autonomous agent / hypothesis 直通 assertion / learning 自动改规则。
