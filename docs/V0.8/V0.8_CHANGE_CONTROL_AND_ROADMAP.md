## 3. P0 / P1 / P2 风险分级

### P0（触发即 STOP）
- V0.5/V0.6/V0.7 frozen 语义需要修改（含 akb_assertions 状态机扩张）；
- hypothesis 以任何形态进入 V0.5 图或 akb_assertions 独立于治理直通；
- provenance 无法承载 hypothesis 生命周期（NO-MIGRATION 路径不可行且方案 b
  未获批准）。

### P1（设计已含解法，实现期落地）
- provenance-only 存储的查询面性能（EvolutionView JOIN 推导）——若不可行，
  走方案 b（migration 16）需显式批准；
- verdict 的 evidence 引用校验深度（存在性 vs 完整五级链回溯）——实现期定标，
  默认存在性 + provenance_ref 完整性。

### P2（accepted 候选）
- hypothesis 陈旧度提醒（open 长期无 verdict）；
- VerificationTask 指派队列视图；
- hypothesis 与 V0.7 policy_ref 的联动过滤（按域列 hypothesis）。

## 4. Out of Scope（V0.9+ / 永久）

- V0.9+：multi-step causal reasoning（需因果 ontology 先冻结）、runtime
  optimization（registry 持久化/批量注入/查询分页）、hypothesis 自动实验设计；
- 永久禁止：LLM as source of truth / vector DB / embedding / distributed /
  autonomous agent / hypothesis 直通 assertion / learning 自动改规则。
