## 3. Contract：HypothesisRuntime

```text
create(statement, origin, *, context_ref=None, actor_id) -> Hypothesis
    input: statement（形态化或文本）；origin ∈ {"reasoning","human"}
    identity: hyp_id = "hyp_"+SHA256(canonical_json({statement, origin,
              context_ref}))[:16]——同输入同 id（deterministic）
    failure: E-V08-HYPOTHESIS-INVALID（空 statement/origin 非法/context 缺失）
    provenance: graph:hypothesis-create（statement 摘要 + origin + context_ref）

verdict(hypothesis_id, verdict, *, evidence_refs, actor_id) -> Hypothesis
    input: verdict ∈ {"support","refute","inconclusive"}；actor 必须 human-actor
           （system/agent/llm 拒绝——E-V08-NOT-HUMAN）
    failure: E-V08-VERDICT-INVALID（verdict 值非法/hypothesis 已 closed/
             evidence 引用不存在——fail-closed 不 fabricate）
    provenance: graph:hypothesis-verdict（verdict + evidence_refs + 快照）
    status 变更: open → supported/refuted；inconclusive 保持 open（记录裁决史）

withdraw(hypothesis_id, *, actor_id) -> Hypothesis
    —— human 撤回（open → withdrawn；已 supported/refuted 不可撤回）

promote_request(hypothesis_id, *, actor_id) -> PromotionCandidate
    —— 仅 supported 状态可发起；产出"提案"（非事实）——提案经 Governance
       human 批准后走 V0.4 create_candidate（inferred/candidate 态入
       akb_assertions）→ 正常治理晋升；inferred→asserted 禁令不变
    provenance: graph:hypothesis-promote-request
```

## 4. Contract：EvolutionView（只读）

```text
trace(assertion_id) -> EvolutionPath
    —— candidate → validated/rejected/... 演化路径（transition 审计序列）+
       关联 hypothesis/verdict 引用（provenance JOIN 推导，零独立存储）
by_hypothesis(hypothesis_id) -> {verdicts, linked_promotions}
    —— 零写操作；canonical 排序
```
